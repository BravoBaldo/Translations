Release notes for 6.1 (blacksail)

This document lists new features and enhancements for the Yocto Project 6.1 Release (codename "blacksail"). For a list of breaking changes and migration guides, see the Migration notes for 6.1 (blacksail) section.

New Features / Enhancements in 6.1

  • Linux kernel 7.2, gcc 16.2, glibc 2.44, LLVM 23.1.1, and over 300 other recipe upgrades

  • Minimum Python version required on the host: 3.9.

  • Kernel-related changes:

    • kernel-module-split: Return list of values in extract_modinfo (43da9b9)

    • kernel: Disable module tarball deployment (MODULE_TARBALL_DEPLOY) by default (f51d48c)

    • linux-yocto: Remove CVE exclusion list as sbom-cve-check does this itself (596ad6c)

    • kernel-fit-image:

      • Validate key files expected by mkimage for the selected algorithm (7570ab5)

      • Do not include kernel property in DTBO configuration sub-nodes (06ed340)

      • Fix operation with KERNEL_DTBVENDORED set to "1" (4297b94)

      • Add KERNEL_DTBVENDORED support for FIT_CONF_DEFAULT_DTB (3bceb2d)

      • Make kernel entry point and load address optional (54c4b48)

      • Avoid shadowing os stdlib import (fe1b5a0)

      • Introduce FIT_OS variable to override 'os' field (dc00e83)

      • Reference the boot script as "script" (6bb0775)

      • Skip sign key check for PKCS #11 URI (b606b71)

      • Don't add configuration hash node when signing is enabled (7346ffe)

    • kernel-arch: Add Clang toolchain support (928d819)

    • kernel-arch: Fall back to GNU ld unless ld-is-lld is in DISTRO_FEATURES (f92bfb5)

    • kernel-yocto: Set CLANG_FLAGS for kernel config checks when using Clang (e88ee79)

    • linux-yocto-dev: Enable BSP config audit reporting (through KCONF_BSP_AUDIT_LEVEL) (c98e839)

    • kernel-devsrc: Install sources required for BPF host tools (cf5b627)

    • kernel-yocto-rust: Add Clang toolchain check for riscv64 (2b22849)

    • lib/oe/kernel_module.py: Re-sign kernel modules after package stripping process (a608d10)

    • kernel-module-split: Don't re-sign compressed kernel modules (3483d02)

  • New core recipes:

    • python3-vcs-versioning: Added as a new dependency of the python3-setuptools-scm recipe (507bb52)

    • cgo-helloworld: A Go example recipe with cgo enabled (204e4f7)

    • jansson: Add a recipe from meta-oe, as it is a new hard dependency of the igt-gpu-tools recipe (2b6e7d0)

    • packagegroup-core-buildessential-rust: A packagegroup to provide the on-target dependencies required for building Rust-based kernel modules, including the Rust toolchain, bindgen, and libclang (500b45f)

    • nativesdk-packagegroup-sdk-host-rust: Similar to packagegroup-core-buildessential-rust but for building Rust-based kernel modules in the SDK (a05c097)

    • nativesdk-packagegroup-sdk-host-clang: nativesdk packagegroup providing the Clang, lld, and llvm-bin dependencies needed to build external/out-of-tree modules in the SDK using the LLVM/Clang toolchain (2b1db6e)

    • gstreamer1.0-plugins-rs: GStreamer Rust plugins (3a2b032)

    • rust-source: Recipe that fetches, unpacks, and patches the rustc source tree into a "work-shared" location (395fe16)

    • libzip: Added because it is a dependency of various tools (f17e875)

    • mesa-libclc: New recipe for forking libclc for Rusticl purposes in Mesa (956aaf3)

    • libtracefs: Added as powertop version 2.16 requires it (3c3f227)

    • libfaketime: Used for reproducibility testing (f3a4faa)

    • python3-tomlkit: New dependency of hatchling (46d3b26)

  • New core classes:

    • python_uv_build: Used to build Python recipes with uv_build, a slimmed down version of uv (c535a9f)

    • upstream-stable-release-point: Helper class for setting the UPSTREAM_STABLE_RELEASE_REGEX variable with STABLE_VERSION_PARTS (a1e069d)

    • python_pbr: Used to build Python recipes with the Python Build Reasonableness backend (b9f3b36)

  • New variables:

    • UBOOT_FIT_CONF_DESC allows configuring the description property of the configuration node of a U-Boot FIT image (df16e4a)

    • KERNEL_TOOLCHAIN: Allows specifying the toolchain to use to build the Linux kernel (0e3756e)

    • FIT_OS: Controls the os field of the FIT image built with the kernel-fit-image class (dc00e83)

    • CARGO_PROFILE: Allows selecting the cargo profile to use (--profile) (d4de7d0)

  • OpenEmbedded-Core (OE-Core) library changes:

    • oe/lsb: Only read /etc/os-release (1331c5f)

    • oe/utils: Drop all_distro_features() (28d32a9)

      • Drop opencl from DISTRO_FEATURES_FILTER_NATIVE and DISTRO_FEATURES_FILTER_NATIVESDK (f810998)

    • useradd*: Add support for the USERMOD_PARAM variable, acting as a replacement of the GROUPMEMS_PARAM variable (b8da733, cec67e2)
