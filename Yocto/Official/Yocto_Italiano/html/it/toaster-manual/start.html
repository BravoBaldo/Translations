2 Preparazione all'Uso di Toaster

Questo capitolo descrive come preparare il sistema per utilizzare Toaster.

2.1 Impostazione dei Requisiti di Sistema di Base

Prima di poter utilizzare Toaster, è necessario configurare il sistema di build per eseguire Yocto Project. Per fare ciò, seguire le istruzioni nella sezione "Preparing the Build Host" del Manuale di Sviluppo dei Task di Yocto Project. Per Ubuntu/Debian, potrebbe essere necessario installare anche pip3.

$ sudo apt install python3-pip

2.2 Impostazione delle Dipendenze di Sistema di Toaster

Toaster richiede dipendenze Python aggiuntive per funzionare. Un file di requisiti di Toaster denominato toaster-requirements.txt definisce le dipendenze Python. Il file di requisiti si trova nella directory bitbake, che si trova nella directory principale della Source Directory (ad esempio poky/bitbake/toaster-requirements.txt). Le dipendenze vengono visualizzate in un formato compatibile con pip.

2.2.1 Installare i Pacchetti di Toaster

È necessario installare i pacchetti richiesti da Toaster. Usare questo comando:

$ pip3 install --user -r bitbake/toaster-requirements.txt

Il comando precedente installa i moduli Toaster necessari in una cache locale di Python 3 nella directory $HOME. La cache si trova effettivamente in $HOME/.local. Per vedere quali pacchetti sono stati installati nella directory $HOME, eseguire il seguente comando:

$ pip3 list installed --local

Se si deve rimuovere qualcosa, il seguente comando funziona:

$ pip3 uninstall PackageNameToUninstall
