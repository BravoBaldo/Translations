Manuale Introduttivo e Concetti di Yocto Project

Benvenuti nel Manuale Introduttivo e Concetti di Yocto Project! Questo manuale presenta Yocto Project fornendo concetti, una panoramica del software, le migliori pratiche (BKM) e qualsiasi altra informazione introduttiva di alto livello adatta a un nuovo utente di Yocto Project.

Ecco cosa c'è in questo manuale:

  • Introduzione a Yocto Project: Questo capitolo fornisce un'introduzione a Yocto Project. Si vedranno le caratteristiche e le sfide di Yocto Project, il modello a layer, i componenti e i tool, i metodi di sviluppo, la distribuzione di riferimento Poky, il flusso di lavoro di OpenEmbedded Build System e alcuni termini base di Yocto.

  • L'Ambiente di Sviluppo di Yocto Project: Questo capitolo illustrerà l'ambiente di sviluppo di Yocto Project. In questo si conoscerà l'open source, gli host di sviluppo, i repository del codice sorgente di Yocto Project, i flussi di lavoro che utilizzano Git e Yocto Project, un'introduzione a Git e informazioni sulle licenze.

  • Concetti di Yocto Project : Questo capitolo presenta diversi concetti relativi a Yocto Project. Si troveranno informazioni concettuali su componenti, sviluppo, toolchain cross-compilation e altro ancora.

Questo manuale non include quanto segue:

  • Istruzioni Dettagliate per i Task di Sviluppo: Le procedure dettagliate si trovano in altri manuali all'interno della documentazione di Yocto Project. Ad esempio, il manuale Manuale di Sviluppo dei Task di Yocto Project fornisce esempi su come eseguire diversi task di sviluppo. Un altro esempio è il manuale Manuale di Sviluppo di Applicazioni Yocto Project e Software Development Kit (SDK/eSDK), che contiene istruzioni dettagliate su come installare un SDK, utilizzato per sviluppare applicazioni per l'hardware di destinazione [target].

  • Materiale di Riferimento: Questo tipo di materiale si trova in un apposito manuale di riferimento. Ad esempio, le variabili di sistema sono documentate nel file Yocto Project Reference Manual. Un altro esempio è il file Manuale del Board Support Package (BSP) di Yocto Project, che contiene informazioni di riferimento sui BSP (Business Support Package).

  • Informazioni pubbliche dettagliate non specifiche di Yocto Project: Ad esempio, informazioni esaustive su come utilizzare il Source Control Manager Git sono reperibili più facilmente tramite ricerche su Internet e la documentazione ufficiale di Git, piuttosto che attraverso la documentazione di Yocto Project.
