Ecco i pacchetti necessari per creare un'immagine su un sistema senza interfaccia grafica con una distribuzione Linux Ubuntu o Debian supportata:

sudo apt-get install build-essential chrpath cpio debianutils diffstat file gawk gcc git iputils-ping libacl1 libcrypt-dev locales python3 python3-git python3-jinja2 python3-pexpect python3-pip python3-subunit socat texinfo unzip wget xz-utils zstd

È inoltre necessario assicurarsi che sia abilitata la localizzazione en_US.UTF-8:

$ locale --all-locales | grep en_US.utf8

In caso contrario, è possibile riconfigurare il pacchetto locales per aggiungerla (richiede una shell interattiva):

$ sudo dpkg-reconfigure locales

Nota

  • Se non si utilizza una shell interattiva, dpkg-reconfigure non funzionerà come previsto. Per aggiungere la localizzazione, è necessario modificare il file /etc/locale.gen per aggiungere/decommentare la localizzazione en_US.UTF-8. Un modo semplice per farlo come root è il seguente:

    $ echo "en_US.UTF-8 UTF-8" >> /etc/locale.gen
$ locale-gen

  • Se il sistema di build ha installato il pacchetto oss4-dev, si potrebbero riscontrare errori di compilazione di QEMU a causa dell'installazione, da parte del pacchetto, di una propria versione personalizzata di /usr/include/linux/soundcard.h sul sistema Debian. Se ci si imbatte in questa situazione, provare una di queste soluzioni:

    $ sudo apt build-dep qemu
$ sudo apt remove oss4-dev
