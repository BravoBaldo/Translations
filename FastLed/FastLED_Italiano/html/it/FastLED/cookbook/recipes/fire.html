  • Animazioni - Concetti di base e tempi di animazione

Si imparerà:

  • Come simulare fenomeni naturali utilizzando array di calore e algoritmi di diffusione

  • Mappatura di dati astratti (valori di calore) in output visivi (colori dei LED) tramite palette

  • egolazione dei parametri (raffreddamento, scintille) per creare diversi comportamenti del fuoco

  • Utilizzo di array paralleli per memorizzare i dati di stato insieme ai dati di colore dei LED

Effetto del Fuoco Base¶

#define NUM_LEDS 60
CRGB leds[NUM_LEDS];
byte heat[NUM_LEDS];

void fire() {
    // Step 1: Cool down every cell a little
    for (int i = 0; i < NUM_LEDS; i++) {
        heat[i] = qsub8(heat[i], random8(0, ((55 * 10) / NUM_LEDS) + 2));
    }

    // Step 2: Heat from each cell drifts 'up' and diffuses a little
    for (int k = NUM_LEDS - 1; k >= 2; k--) {
        heat[k] = (heat[k - 1] + heat[k - 2] + heat[k - 2]) / 3;
    }

    // Step 3: Randomly ignite new 'sparks' at the bottom
    if (random8() < 120) {
        int y = random8(7);
        heat[y] = qadd8(heat[y], random8(160, 255));
    }

    // Step 4: Map heat to LED colors
    for (int j = 0; j < NUM_LEDS; j++) {
        // Scale heat to 0-240 for palette index
        byte colorIndex = scale8(heat[j], 240);

        // Use HeatColors palette
        leds[j] = ColorFromPalette(HeatColors_p, colorIndex);
    }
}

void loop() {
    fire();
    FastLED.show();
    delay(15);
}

Fuoco Personalizzabile¶

Controllare il comportamento del fuoco con parametri regolabili:

void customFire(uint8_t cooling, uint8_t sparking) {
    // cooling: 20-100 (higher = faster cooling)
    // sparking: 50-200 (higher = more sparks)

    // Cool down
    for (int i = 0; i < NUM_LEDS; i++) {
        heat[i] = qsub8(heat[i], random8(0, ((cooling * 10) / NUM_LEDS) + 2));
    }

    // Heat drift upward
    for (int k = NUM_LEDS - 1; k >= 2; k--) {
        heat[k] = (heat[k - 1] + heat[k - 2] + heat[k - 2]) / 3;
    }

    // Ignite sparks
    if (random8() < sparking) {
        int y = random8(7);
        heat[y] = qadd8(heat[y], random8(160, 255));
    }

    // Map to colors
    for (int j = 0; j < NUM_LEDS; j++) {
        leds[j] = ColorFromPalette(HeatColors_p, scale8(heat[j], 240));
    }
}

Come Funziona¶

L’effetto fuoco utilizza un approccio di simulazione del calore:

  1. Raffreddamento: Ogni “cella” si raffredda casualmente nel tempo

  2. Diffusione del calore: Il calore sale e si diffonde alle celle vicine

  3. Sparking: Nuove scintille vengono accese casualmente nella parte inferiore

  4. Mappatura dei colori: I valori di calore vengono mappati ai colori utilizzando la palette HeatColors

Spiegazione dei Parametri¶

  • Cooling (20-100): Controlla la velocità con cui il fuoco si spegne

    • Valori più bassi = fuoco più lento e uniforme

    • Valori più alti = fuoco più veloce e caotico

  • Sparking (50-200): Controlla il numero di nuove scintille create

    • Valori più bassi = fiamme sparse e delicate

    • Valori più alti = fuoco intenso e vigoroso

Suggerimenti per l’Uso¶

  • Orientare la striscia LED verticalmente con l’input dati in basso per un effetto visivo ottimale

  • Per un effetto simile a un falò, usare i parametri di default: customFire(55, 120)

  • Per un delicato effetto candela, provare: customFire(30, 80)

  • Per un inferno intenso, provare: customFire(80, 180)

  • Regolare delay(15) per controllare la velocità dell’animazione (più basso = più veloce)
