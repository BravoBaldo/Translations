Effetti Scintillìo/Luccichìo¶

Livello di Difficoltà: ⭐⭐ Intermedio Tempo di Completamento: 25-35 minuti Prerequisiti:

  • Animazioni - fadeToBlackBy() e concetti di temporizzazione

  • Teoria del Colore - Spazio colore HSV per colori casuali

  • Funzioni Matematiche - Funzioni random8() e random16()

  • Fusione - Variazione della luminosità e tecniche di dissolvenza

Si imparerà:

  • Come creare animazioni basate sulla probabilità utilizzando i controlli di soglia random8()

  • Selezione sicura di posizioni LED casuali con random16(NUM_LEDS)

  • Regolazione delle velocità di dissolvenza e delle soglie di probabilità per controllare la densità e la persistenza dello scintillìo

  • Creazione di varianti (campo stellare, luci da festa, lucciole) regolando i parametri

  • Utilizzando la variazione di luminosità e la temporizzazione per aggiungere profondità e dimensione agli effetti di luccichìo

Stelle scintillanti casuali ed effetti di luccichìo.

Scintillìo Semplice¶

Effetto scintillante di base con colori casuali:

void twinkle() {
    // Fade all LEDs slightly
    fadeToBlackBy(leds, NUM_LEDS, 32);

    // Add new twinkles
    if (random8() < 50) {  // 50/255 chance per frame
        int pos = random16(NUM_LEDS);
        leds[pos] = CHSV(random8(), 200, 255);  // Random color
    }
}

Scintillìo Colorato¶

Effetto luccichìo con un colore specifico:

void coloredTwinkle(CRGB color) {
    fadeToBlackBy(leds, NUM_LEDS, 20);

    // Add multiple twinkles per frame
    for (int i = 0; i < 3; i++) {
        if (random8() < 100) {
            int pos = random16(NUM_LEDS);
            leds[pos] = color;
            leds[pos].fadeToBlackBy(random8(50, 150));  // Vary brightness
        }
    }
}

Sparkle (Flash Istantaneo)¶

Luccichii rapidi e lampeggianti su sfondo scuro:

void sparkle(CRGB color, int count, int delayMs) {
    // Turn off all LEDs
    FastLED.clear();

    // Flash random LEDs
    for (int i = 0; i < count; i++) {
        int pos = random16(NUM_LEDS);
        leds[pos] = color;
    }

    FastLED.show();
    delay(delayMs);
}

White Twinkle (Luci di Natale)¶

Sfondo bianco caldo con brillanti scintillii bianchi:

void whiteTwinkle() {
    // Background: warm white
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = CRGB(255, 147, 41);
        leds[i].fadeToBlackBy(200);  // Dim background
    }

    // Random bright twinkles
    for (int i = 0; i < 5; i++) {
        if (random8() < 80) {
            int pos = random16(NUM_LEDS);
            leds[pos] = CRGB::White;
        }
    }

    FastLED.show();
    delay(100);
}

Come Funziona¶

L’effetto luccichìo crea l’effetto di una notte stellata:

  1. Fading: Abbassamento graduale di tutti i LED per creare scie

  2. Selezione casuale: Scelta casuale di LED da accendere

  3. Variazione di luminosità: Utilizzo di diversi livelli di luminosità per creare profondità

  4. Variazione di colore: Colori casuali o specifici opzionali

Spiegazione dei Parametri¶

  • Velocità di dissolvenza (in fadeToBlackBy): Velocità con cui i LED si attenuano

    • Valori più bassi (10-20) = scie lunghe e fluide

    • Valori più alti (50+) = scintillii rapidi e vivaci

  • Probability (in random8() check): Frequenza con cui compaiono nuovi scintillii

    • Valori più bassi (20-50) = scintillii sparsi e occasionali

    • Valori più alti (100-200) = frequenti, scintillii densi

  • Count: Numero di scintillii simultanei

    • 1-3 per un effetto delicato

    • 5-10 per un campo di stelle intenso

Suggerimenti per l’Uso¶

Per un effetto campo di stelle:

void loop() {
    fadeToBlackBy(leds, NUM_LEDS, 32);
    if (random8() < 30) {
        leds[random16(NUM_LEDS)] = CRGB::White;
    }
    FastLED.show();
    delay(20);
}

Per luci da festa:

void loop() {
    fadeToBlackBy(leds, NUM_LEDS, 50);
    for (int i = 0; i < 5; i++) {
        if (random8() < 100) {
            leds[random16(NUM_LEDS)] = CHSV(random8(), 255, 255);
        }
    }
    FastLED.show();
    delay(50);
}

Per lucciole:

void loop() {
    fadeToBlackBy(leds, NUM_LEDS, 10);  // Very slow fade
    if (random8() < 20) {
        leds[random16(NUM_LEDS)] = CRGB(255, 255, 100);  // Yellowish
    }
    FastLED.show();
    delay(30);
}

Varianti¶

Scintillìo Basato sulla Palette:

void paletteTwinkle(CRGBPalette16 palette) {
    fadeToBlackBy(leds, NUM_LEDS, 40);
    if (random8() < 60) {
        int pos = random16(NUM_LEDS);
        leds[pos] = ColorFromPalette(palette, random8(), 255, LINEARBLEND);
    }
}

Arcobaleno Scintillante:

void rainbowTwinkle() {
    fadeToBlackBy(leds, NUM_LEDS, 30);
    if (random8() < 80) {
        int pos = random16(NUM_LEDS);
        leds[pos] = CHSV(random8(), 255, 255);
    }
}
