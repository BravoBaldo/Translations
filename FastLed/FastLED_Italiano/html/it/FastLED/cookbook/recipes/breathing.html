Effetto Respiro¶

Livello di Difficoltà: ⭐⭐ Intermedio Tempo di Completamento: 30-40 minuti Prerequisiti:

  • Pattern di Base: Animazioni - Comprensione del timing e delle variabili statiche

  • Concetti Fondamentali: Teoria del Colore - Spazi colore RGB e HSV

  • Intermedio: Matematica - beatsin8() e funzioni d’onda

  • Intermedio: Fusione - fadeToBlackBy() per il controllo della luminosità

Si imparerà:

  • Come creare animazioni fluide con pulsazioni/respiri utilizzando la funzione sinusoidale beatsin8()

  • Controllo della velocità di “breathing” [respirazione] con il parametro BPM (respiri al minuto) e della profondità con intervallo di luminosità minimo/massimo

  • Creazione di effetti di respirazione a fasi in cui i LED pulsano in sequenza utilizzando il parametro offset fase

  • Combinazione di più schemi di respirazione (doppi colori, respirazione arcobaleno, respirazione suddivisa in fasi diverse)

  • Applicazione della respirazione a casi d’uso pratici: luci per la meditazione, indicatori di allerta, onde dell’oceano, schemi di battito cardiaco

Animazioni fluide di pulsazioni/respirazioni.

Respirazione Semplice¶

Effetto respirazione base con un colore pieno:

void breathe(CRGB color) {
    // Use beatsin8 for smooth sine wave (0-255)
    uint8_t brightness = beatsin8(12);  // 12 BPM

    // Set all LEDs to color with varying brightness
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = color;
        leds[i].fadeToBlackBy(255 - brightness);
    }
}

Respirazione Multicolore¶

Effetto respirazione con colori che cambiano lentamente:

void colorBreathe() {
    static uint8_t hue = 0;

    // Brightness oscillates
    uint8_t brightness = beatsin8(10, 50, 255);

    // Hue slowly changes
    EVERY_N_MILLISECONDS(50) {
        hue++;
    }

    fill_solid(leds, NUM_LEDS, CHSV(hue, 255, brightness));
}

Respirazione con Fase¶

I LED respirano in sequenza, creando un effetto onda:

void phasedBreathe() {
    for (int i = 0; i < NUM_LEDS; i++) {
        // Each LED has a phase offset
        uint8_t brightness = beatsin8(
            15,                      // Speed
            50,                      // Minimum brightness
            255,                     // Maximum brightness
            0,                       // Time offset
            i * (255 / NUM_LEDS)    // Phase per LED
        );

        leds[i] = CHSV(160, 255, brightness);
    }
}

Respirazione Doppia¶

Due colori alternati, respirazione in fasi opposte:

void dualBreathe() {
    uint8_t brightness1 = beatsin8(8);
    uint8_t brightness2 = 255 - brightness1;  // Inverse

    for (int i = 0; i < NUM_LEDS; i++) {
        CRGB color1 = CRGB::Blue;
        CRGB color2 = CRGB::Purple;

        color1.fadeToBlackBy(255 - brightness1);
        color2.fadeToBlackBy(255 - brightness2);

        leds[i] = color1 + color2;  // Blend both colors
    }
}

Come Funziona¶

L’effetto respirazione utilizza funzioni sinusoidali per creare oscillazioni fluide:

  1. beatsin8(): Genera valori di onda sinusoidale fluida (0-255)

  2. Parametro BPM: Controlla la velocità di respirazione (respiri al minuto)

  3. Valori Min/Max: Imposta l’intervallo di profondità della respirazione

  4. offset Phase: Crea modelli di onda quando diversi per LED

Spiegazione dei Parametri¶

beatsin8(bpm, min, max, timebase, phase_offset)

  • bpm (beats per minute): Controlla la velocità respiratoria

    • 5-10 = respirazione lenta e rilassante

    • 12-15 = ritmo respiratorio normale

    • 20+ = pulsazione rapida

  • min/max: Intervallo di luminosità

    • (0, 255) = range completo, da completamente spento a completamente luminoso

    • (50, 255) = mai completamente spento

    • (100, 200) = pulsazione delicata

  • phase_offset: Sfalsa la temporizzazione tra i LED

    • 0 = tutti i LED respirano contemporaneamente

    • i * (255 / NUM_LEDS) = onda uniforme sulla striscia

Esempi di Utilizzo¶

Luci rilassanti per meditazione:

void loop() {
    uint8_t brightness = beatsin8(6, 30, 200);  // Slow, never too dim
    fill_solid(leds, NUM_LEDS, CHSV(160, 180, brightness));  // Soft blue
    FastLED.show();
}

Indicatore di allarme:

void loop() {
    uint8_t brightness = beatsin8(30);  // Fast breathing
    fill_solid(leds, NUM_LEDS, CRGB::Red);
    FastLED.setBrightness(brightness);
    FastLED.show();
}

Onde dell’oceano:

void loop() {
    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t brightness = beatsin8(8, 50, 255, 0, i * 4);
        leds[i] = CHSV(160, 255, brightness);  // Blue
    }
    FastLED.show();
}

Varianti¶

Respirazione Arcobaleno:

void rainbowBreathe() {
    static uint8_t hue = 0;
    uint8_t brightness = beatsin8(12);

    fill_rainbow(leds, NUM_LEDS, hue, 255 / NUM_LEDS);

    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i].fadeToBlackBy(255 - brightness);
    }

    EVERY_N_MILLISECONDS(20) { hue++; }
}

Respirazione a Sezioni:

void sectionBreathe() {
    int section1 = NUM_LEDS / 3;
    int section2 = (NUM_LEDS * 2) / 3;

    uint8_t b1 = beatsin8(10);
    uint8_t b2 = beatsin8(10, 0, 255, 0, 85);   // 1/3 phase shift
    uint8_t b3 = beatsin8(10, 0, 255, 0, 170);  // 2/3 phase shift

    fill_solid(&leds[0], section1, CHSV(0, 255, b1));
    fill_solid(&leds[section1], section2 - section1, CHSV(96, 255, b2));
    fill_solid(&leds[section2], NUM_LEDS - section2, CHSV(160, 255, b3));
}

Heartbeat:

void heartbeat() {
    // Quick double-beat pattern
    static uint16_t beatTimer = 0;
    uint8_t brightness = 0;

    uint16_t beatPhase = beatTimer % 1000;

    if (beatPhase < 100) {
        brightness = map(beatPhase, 0, 100, 0, 255);
    } else if (beatPhase < 200) {
        brightness = map(beatPhase, 100, 200, 255, 0);
    } else if (beatPhase < 300) {
        brightness = map(beatPhase, 200, 300, 0, 255);
    } else if (beatPhase < 400) {
        brightness = map(beatPhase, 300, 400, 255, 0);
    }

    fill_solid(leds, NUM_LEDS, CRGB::Red);
    FastLED.setBrightness(brightness);
    FastLED.show();

    beatTimer += 20;
    delay(20);
}

Suggerimenti¶

  • Usare BPM più lenti (6-10) per effetti ambientali/rilassanti

  • Usare BPM più veloci (15-30) per effetti di allerta/notifica

  • Combinare con cambi di colore per effetti più dinamici

  • Regolare la luminosità minima per evitare l’oscurità completa

  • Usare offset di fase per creare modelli di onde viaggianti
