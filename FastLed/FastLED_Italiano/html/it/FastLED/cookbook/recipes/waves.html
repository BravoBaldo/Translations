Pattern di Onde¶

Livello di Difficoltà: ⭐⭐ Intermedio Tempo di Completamento: 35-45 minuti Prerequisiti:

  • Pattern di Base: Animazioni - Comprensione del timing e delle variabili statiche

  • Concetti Fondamentali: Teoria del Colore - Spazi colore RGB e HSV

  • Intermedio: Matematica - sin8(), beatsin8() e funzioni d’onda trigonometriche (dipendenza dal core)

  • Intermedio: Fusione - fadeToBlackBy() per effetti scia

Si imparerà:

  • Come creare animazioni di onde in movimento utilizzando la funzione trigonometrica sin8() con parametri di fase e posizione

  • Controllo delle caratteristiche delle onde: velocità tramite incremento di fase, frequenza tramite moltiplicatore di posizione, lunghezza d’onda tramite diffusione

  • Sovrapposizione di più onde per creare modelli organici complessi (multi-onda, plasma, simulazione del mare)

  • Creazione di effetti di onde direzionali: increspature che si espandono dal punto centrale, onde doppie con offset di fase, picchi in movimento

  • Applicazione di tecniche ondulatorie a modelli pratici: onde colorate che si muovono lungo una striscia, scanner fluidi con sinusoide “falloff”, onde oceaniche (Pacifica), effetto “pride” con molteplici parametri modulati

Vari effetti di onde, tra cui onde sinusoidali, onde colorate e motivi ispirati all’oceano.

Onda Sinusoidale¶

Modello base di onda sinusoidale che si muove lungo la striscia:

void sineWave() {
    static uint8_t phase = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        // Calculate sine wave brightness for each LED
        uint8_t brightness = sin8(phase + (i * 255 / NUM_LEDS));
        leds[i] = CHSV(160, 255, brightness);
    }

    phase += 4;  // Wave speed
}

Onda Colorata¶

Onda di colori cangianti che si muove lungo la striscia:

void colorWave() {
    static uint8_t hue = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        // Each LED gets a different hue based on position
        uint8_t ledHue = hue + (i * 10);
        leds[i] = CHSV(ledHue, 255, 255);
    }

    hue++;  // Shift colors
}

Onde Multiple¶

Combinare tre onde con velocità e fasi diverse:

void multiWave() {
    for (int i = 0; i < NUM_LEDS; i++) {
        // Combine three waves with different speeds and phases
        uint8_t wave1 = sin8(millis() / 10 + i * 8);
        uint8_t wave2 = sin8(millis() / 20 + i * 12);
        uint8_t wave3 = sin8(millis() / 30 + i * 16);

        uint8_t combined = (wave1 + wave2 + wave3) / 3;
        leds[i] = CHSV(combined, 255, 255);
    }
}

Pacifica (Onde dell’Oceano)¶

Simulazione complessa di onde oceaniche con più livelli:

void pacifica() {
    // Four layers of waves
    pacifica_one_layer(1, 26, 100, 11);
    pacifica_one_layer(2, 13, 65, 17);
    pacifica_one_layer(3, 8, 43, 23);
    pacifica_one_layer(4, 5, 28, 29);

    // Add whitecaps
    pacifica_add_whitecaps();

    // Deepen colors
    pacifica_deepen_colors();
}

void pacifica_one_layer(uint8_t layer, uint16_t speed, uint8_t scale, uint8_t offset) {
    uint16_t dataOffset = layer * NUM_LEDS;
    for (int i = 0; i < NUM_LEDS; i++) {
        uint16_t angle = (millis() / speed) + (i * scale) + offset;
        uint8_t level = sin8(angle) / 2 + 127;
        leds[i] += CHSV(200, 255, level);  // Blue-green
    }
}

void pacifica_add_whitecaps() {
    uint8_t basethreshold = beatsin8(9, 55, 65);
    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t threshold = basethreshold + (i * 2);
        if (leds[i].blue > threshold) {
            uint8_t overage = leds[i].blue - threshold;
            leds[i] += CRGB(overage, overage, overage);
        }
    }
}

void pacifica_deepen_colors() {
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i].blue = scale8(leds[i].blue, 145);
        leds[i].green = scale8(leds[i].green, 200);
    }
}

Effetto Increspatura¶

Espansione delle “ripple” [increspature] da un punto centrale:

int center = NUM_LEDS / 2;
uint8_t maxDistance = NUM_LEDS / 2;

void ripple() {
    static uint8_t wavePos = 0;

    fadeToBlackBy(leds, NUM_LEDS, 10);

    for (int i = 0; i < NUM_LEDS; i++) {
        // Distance from center
        uint8_t distance = abs(i - center);

        // Create ripple
        if (distance == wavePos || distance == wavePos - 5) {
            leds[i] = CHSV(160, 255, 255);
        }
    }

    wavePos++;
    if (wavePos >= maxDistance) wavePos = 0;
}

Come Funziona¶

I modelli di onda utilizzano funzioni trigonometriche per creare un movimento fluido e fluido:

  1. sin8(): Funzione seno a 8 bit (veloce ed efficiente)

  2. Phase: Controlla la posizione nel ciclo dell’onda

  3. Frequency: Determinata dal moltiplicatore applicato alla posizione

  4. Speed: Controllata incrementando il valore di fase

Spiegazione dei Parametri¶

Componenti dell’Onda Sinusoidale:

  • phase: Posizione corrente nell’animazione (incremento per il movimento)

  • i * moltiplicatore: Distribuisce l’onda sulla striscia (più alto = più onde)

  • incremento di fase: Controlla la velocità (più alto = più veloce movimento)

Frequenza d’Onda:

  • Moltiplicatore piccolo (2-5): Lunghezze d’onda lunghe e delicate

  • Moltiplicatore medio (8-15): Motivi d’onda visibili

  • Moltiplicatore grande (20+): Onde rapide e compresse

Esempi di Utilizzo¶

Scanner fluido:

void loop() {
    static uint8_t pos = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        int distance = abs(i - pos);
        uint8_t brightness = qadd8(sin8((255 / NUM_LEDS) * distance), 50);
        leds[i] = CHSV(0, 255, brightness);
    }

    pos++;
    if (pos >= NUM_LEDS) pos = 0;

    FastLED.show();
    delay(20);
}

Onda Pride:

void pride() {
    static uint16_t sPseudotime = 0;
    static uint16_t sLastMillis = 0;
    static uint16_t sHue16 = 0;

    uint8_t sat8 = beatsin88(87, 220, 250);
    uint8_t brightdepth = beatsin88(341, 96, 224);
    uint16_t brightnessthetainc16 = beatsin88(203, (25 * 256), (40 * 256));
    uint8_t msmultiplier = beatsin88(147, 23, 60);

    uint16_t hue16 = sHue16;
    uint16_t hueinc16 = beatsin88(113, 1, 3000);

    uint16_t ms = millis();
    uint16_t deltams = ms - sLastMillis;
    sLastMillis = ms;
    sPseudotime += deltams * msmultiplier;
    sHue16 += deltams * beatsin88(400, 5, 9);
    uint16_t brightnesstheta16 = sPseudotime;

    for (uint16_t i = 0; i < NUM_LEDS; i++) {
        hue16 += hueinc16;
        uint8_t hue8 = hue16 / 256;

        brightnesstheta16 += brightnessthetainc16;
        uint16_t b16 = sin16(brightnesstheta16) + 32768;

        uint16_t bri16 = (uint32_t)((uint32_t)b16 * (uint32_t)b16) / 65536;
        uint8_t bri8 = (uint32_t)(((uint32_t)bri16) * brightdepth) / 65536;
        bri8 += (255 - brightdepth);

        CRGB newcolor = CHSV(hue8, sat8, bri8);

        uint16_t pixelnumber = i;
        pixelnumber = (NUM_LEDS - 1) - pixelnumber;

        nblend(leds[pixelnumber], newcolor, 64);
    }
}

Varianti¶

Onda Doppia:

void dualWave() {
    static uint8_t phase = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t wave1 = sin8(phase + (i * 8));
        uint8_t wave2 = sin8(phase + (i * 16) + 128);  // Offset phase

        leds[i] = CHSV(wave1, 255, wave2);
    }

    phase += 2;
}

Onda di Plasma:

void plasma() {
    static uint8_t time_offset = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t val1 = sin8(time_offset + i * 8);
        uint8_t val2 = sin8(time_offset * 2 + i * 4);
        uint8_t val3 = sin8(time_offset / 2 + i * 16);

        uint8_t combined = (val1 + val2 + val3) / 3;
        leds[i] = CHSV(combined, 255, 255);
    }

    time_offset++;
}

Picchi Mobili:

void travelingPeaks() {
    static uint8_t peak1 = 0;
    static uint8_t peak2 = NUM_LEDS / 2;

    fadeToBlackBy(leds, NUM_LEDS, 20);

    // Draw peaks with falloff
    for (int i = 0; i < NUM_LEDS; i++) {
        int dist1 = abs(i - peak1);
        int dist2 = abs(i - peak2);

        uint8_t brightness = qadd8(
            qsub8(255, dist1 * 20),
            qsub8(255, dist2 * 20)
        );

        leds[i] += CHSV(160, 255, brightness);
    }

    peak1 = (peak1 + 1) % NUM_LEDS;
    peak2 = (peak2 + 1) % NUM_LEDS;
}

Suggerimenti¶

  • Usare sin8() invece di sin() per prestazioni migliori

  • Combinare più onde per motivi complessi

  • Regolare l’incremento di fase per diverse velocità

  • Usare fadeToBlackBy() con le onde per effetti scia

  • Sperimenta diverse mappature di colore (tonalità, saturazione o luminosità)

  • Sovrapporre le onde sommando i loro risultati

  • Usare millis() per animazioni basate sul tempo che non dipendono dal frame rate
