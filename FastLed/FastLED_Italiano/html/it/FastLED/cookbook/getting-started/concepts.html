Concetti Base¶

Livello di Difficoltà: ⭐ Beginner Tempo di Completamento: 20 minuti Prerequisiti: Nessuno (questo è il punto di partenza!)

Si imparerà:

  • Come indirizzare e controllare i singoli LED di una striscia

  • Differenza tra i modelli di colore RGB e HSV e quando utilizzarli

  • Come configurare FastLED per l’hardware LED specifico

  • Concetti chiave come il controllo della luminosità e le variabili statiche

Idee fondamentali alla base della programmazione LED con FastLED.

Indirizzamento LED¶

Ogni LED della striscia ha un indice (posizione) che inizia da 0.

LED Strip:  [0] [1] [2] [3] [4] [5] ... [59]
             ^                           ^
           First                       Last

È possibile controllare i LED impostando i valori di colore in una matrice:

CRGB leds[60];  // Array for 60 LEDs

leds[0] = CRGB::Red;    // First LED is red
leds[5] = CRGB::Blue;   // Sixth LED is blue

Modelli di Colore¶

FastLED supporta due modelli di colore principali:

RGB (Red, Green, Blue)¶

Ogni canale colore varia da 0 a 255:

CRGB color = CRGB(255, 0, 0);      // Red
CRGB color = CRGB(0, 255, 0);      // Green
CRGB color = CRGB(0, 0, 255);      // Blue
CRGB color = CRGB(255, 255, 255);  // White

HSV (Hue, Saturation, Value) [Tonalità, Saturazione, Valore]¶

  • Tonalità (0-255): Colore (rosso → arancione → giallo → verde → blu → viola → rosso)

  • Saturazione (0-255): Intensità del colore (0 = bianco, 255 = colore pieno)

  • Valore (0-255): Luminosità (0 = spento, 255 = luminosità massima)

CHSV hsv1 = CHSV(0, 255, 255);      // Red
CHSV hsv2 = CHSV(96, 255, 255);     // Green
CHSV hsv3 = CHSV(160, 255, 255);    // Blue

// Automatic conversion to RGB
leds[0] = hsv1;

Perché usare HSV?

  • Creazione più semplice di transizioni di colore fluide (basta cambiare tonalità)

  • Naturale per effetti arcobaleno

  • Semplice controllo della luminosità senza cambiare colore

Il Pattern del Loop Principale¶

Ogni programma FastLED segue questo pattern:

void setup() {
    // 1. Initialize FastLED (runs once)
    FastLED.addLeds<LED_TYPE, DATA_PIN>(leds, NUM_LEDS);
    FastLED.setBrightness(50);
}

void loop() {
    // 2. Calculate/update LED colors
    leds[0] = CRGB::Red;

    // 3. Send colors to LEDs
    FastLED.show();

    // 4. Optional: delay or manage frame rate
    delay(20);
}

Punti chiave:

  • setup() viene eseguito una volta all’avvio - configurare qui i LED

  • loop() viene eseguito ripetutamente - aggiornare qui i colori dei LED

  • Si deve chiamare FastLED.show() per aggiornare effettivamente i LED fisici

  • Le modifiche all’array leds[] non sono visibili finché non si chiama FastLED.show()

Configurazione del Tipo di LED¶

Informare FastLED sul proprio hardware:

#define LED_PIN     5           // Data pin number
#define NUM_LEDS    60          // Number of LEDs
#define LED_TYPE    WS2812B     // Your LED strip type
#define COLOR_ORDER GRB         // Color channel order

CRGB leds[NUM_LEDS];

void setup() {
    FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS);
}

Tipi di LED comuni:

  • WS2812B - Il più comune (NeoPixel)

  • APA102 - DotStar (richiede pin di clock)

  • SK6812 - Simile a WS2812B

Ordini dei colori comuni:

  • GRB - WS2812B (il più comune)

  • RGB - Alcuni WS2811

  • BGR - APA102

Se i colori sono errati, provare valori diversi di COLOR_ORDER.

Controllo della Luminosità¶

Controlla la luminosità complessiva (0-255):

void setup() {
    FastLED.addLeds<LED_TYPE, LED_PIN>(leds, NUM_LEDS);
    FastLED.setBrightness(50);  // 0-255 (50 = ~20% brightness)
}

Suggerimento: Iniziare con una luminosità bassa (50) durante i test per evitare l’affaticamento degli occhi e ridurre il consumo energetico.

Variabili Statiche e Dinamiche¶

Usare le variabili static per ricordare i valori tra le iterazioni del ciclo:

void loop() {
    static uint8_t hue = 0;  // Remembers value across loops

    leds[0] = CHSV(hue, 255, 255);
    FastLED.show();

    hue++;  // Increment for next loop
}

Senza static, la variabile si reimposta a 0 a ogni ciclo.
