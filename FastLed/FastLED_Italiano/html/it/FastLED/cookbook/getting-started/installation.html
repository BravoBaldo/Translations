Installazione e Configurazione¶

Come installare FastLED per l’ambiente di sviluppo.

PlatformIO (Consigliato)¶

PlatformIO offre la migliore esperienza di sviluppo con gestione delle dipendenze, supporto per più schede e configurazione semplice.

Aggiungere FastLED al file platformio.ini:

[env:myboard]
platform = ...
board = ...
lib_deps =
    fastled/FastLED

Arduino IDE¶

  1. Aprire Sketch → Include Library → Manage Libraries

  2. Cercare “FastLED”

  3. Cliccare su Install

  4. Attendere il completamento dell’installazione

  5. Riavviare l’IDE Arduino.

Installazione Manuale¶

Se si deve installare dal codice sorgente:

  1. Scaricare l’ultima versione da GitHub

  2. Estrarre l’archivio

  3. Copiare la cartella FastLED nella directory delle librerie:

    • Windows: Documents\Arduino\libraries\

    • macOS: ~/Documents/Arduino/libraries/

    • Linux: ~/Arduino/libraries/

Verifica¶

Verificare l’installazione con questo programma minimale:

#include <FastLED.h>

void setup() {
    Serial.begin(115200);
    Serial.println("FastLED is installed!");
}

void loop() {
    // Your code here
}

Se compila senza errori, si è pronti!
