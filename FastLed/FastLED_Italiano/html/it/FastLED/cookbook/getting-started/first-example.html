Il Primo Esempio di Lampeggìo¶

Scrivere ed eseguire il primo programma LED con FastLED.

Livello di Difficoltà: ⭐ Beginner Tempo di Completamento: 30 minuti (inclusa la configurazione hardware) Prerequisiti:

  • Concetti FastLED - Comprensione dei concetti base del controllo LED

  • Arduino IDE o PlatformIO installato

  • Striscia LED collegata al microcontrollore

Si imparerà:

  • Come scrivere un programma FastLED completo da zero

  • I pattern essenziali setup() e loop() in azione

  • Come usare fill_solid() per impostare tutti i LED su un unico colore

  • Perché FastLED.show() è necessario per aggiornare la striscia LED

  • Come personalizzare i numeri dei pin, il numero di LED e la temporizzazione per l’hardware

Esempio Completo¶

Questo programma fa lampeggiare tutti i LED tra il rosso e lo spento:

#include <FastLED.h>

// Configuration
#define LED_PIN     5
#define NUM_LEDS    60
#define LED_TYPE    WS2812B
#define COLOR_ORDER GRB

// LED array
CRGB leds[NUM_LEDS];

void setup() {
    // Initialize FastLED
    FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS);
    FastLED.setBrightness(50);  // Start with low brightness
}

void loop() {
    // Turn all LEDs red
    fill_solid(leds, NUM_LEDS, CRGB::Red);
    FastLED.show();
    delay(1000);

    // Turn all LEDs off
    fill_solid(leds, NUM_LEDS, CRGB::Black);
    FastLED.show();
    delay(1000);
}

Come Funziona¶

Fase di Configurazione¶

void setup() {
    FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS);
    FastLED.setBrightness(50);
}

  • FastLED.addLeds<>() - Fornisce informazioni a FastLED sull’hardware

  • FastLED.setBrightness(50) - Imposta la luminosità a circa il 20% (sicuro per i test)

Fase di Loop¶

void loop() {
    fill_solid(leds, NUM_LEDS, CRGB::Red);  // Set all LEDs to red
    FastLED.show();                          // Send to strip
    delay(1000);                             // Wait 1 second

    fill_solid(leds, NUM_LEDS, CRGB::Black); // Set all LEDs to off
    FastLED.show();                          // Send to strip
    delay(1000);                             // Wait 1 second
}

Personalizzazione¶

Cambiare il Pin¶

#define LED_PIN     6  // Use pin 6 instead of 5

Cambiare il Numero di LED¶

#define NUM_LEDS    30  // For a 30-LED strip

Cambia il Colore¶

fill_solid(leds, NUM_LEDS, CRGB::Blue);   // Blue instead of red
fill_solid(leds, NUM_LEDS, CRGB::Green);  // Green
fill_solid(leds, NUM_LEDS, CRGB::Purple); // Purple

Cambia la Velocità di Lampeggìo¶

delay(500);   // Faster (0.5 seconds)
delay(2000);  // Slower (2 seconds)

Risoluzione dei problemi¶

I LED Non si Accendono¶

  1. Controllare i collegamenti di alimentazione - Verificare che 5 V e GND siano collegati

  2. Controllare il pin dati - Assicurarsi che LED_PIN corrisponda al proprio cablaggio

  3. Provare una luminosità diversa - Aumentare a FastLED.setBrightness(100)

  4. Verificare il tipo di LED - Verificare che LED_TYPE corrisponda alla striscia

Colori Errati¶

Provare diversi valori d COLOR_ORDER:

#define COLOR_ORDER GRB  // Try GRB first (most common)
// If that doesn't work, try:
#define COLOR_ORDER RGB
#define COLOR_ORDER BGR

Funziona Solo il Primo LED¶

  • Aggiungere una resistenza da 220-470Ω sulla linea dati

  • Verificare la presenza di LED danneggiati nella striscia

Controllo di LED individuali¶

void loop() {
    // Turn on first 3 LEDs to different colors
    leds[0] = CRGB::Red;
    leds[1] = CRGB::Green;
    leds[2] = CRGB::Blue;

    // Rest of LEDs stay off
    FastLED.show();
    delay(1000);
}

Riempire un Intervallo¶

// Fill LEDs 10-19 with green
fill_solid(&leds[10], 10, CRGB::Green);
