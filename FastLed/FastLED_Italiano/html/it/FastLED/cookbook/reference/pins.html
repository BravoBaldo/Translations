Consigli e configurazioni dei pin specifici per piattaforma per FastLED.

Arduino Uno/Nano (ATmega328)¶

// Any digital pin can be used for data
#define DATA_PIN 6

// Recommended pins for best performance:
// Pins 2-13 (all digital pins work)
// Avoid pins 0,1 (Serial), 13 (LED)

Arduino Mega (ATmega2560)¶

#define DATA_PIN 6

// Many pins available: 2-53
// Best performance: pins 2-13, 44-46

ESP32¶

// Most GPIO pins work, but avoid:
// GPIO 0, 2 (boot pins)
// GPIO 6-11 (flash pins)
// GPIO 34-39 (input only)

// Recommended pins:
#define DATA_PIN 16  // or 17, 18, 19, 21, 22, 23

// For RMT-based output (best):
// GPIO 2, 4, 5, 12-19, 21-23, 25-27, 32-33

// Multiple strips example:
#define STRIP1_PIN 16
#define STRIP2_PIN 17
#define STRIP3_PIN 18

ESP8266¶

// Limited pins available
#define DATA_PIN 2   // GPIO2 (D4 on NodeMCU)

// Other options:
// GPIO0 (D3), GPIO2 (D4), GPIO4 (D2), GPIO5 (D1)
// GPIO12 (D6), GPIO13 (D7), GPIO14 (D5), GPIO15 (D8)

// Avoid during boot: GPIO0, GPIO2, GPIO15

Teensy 4.x¶

// Most pins work, excellent performance
#define DATA_PIN 7

// Recommended for WS2812B: Any pin
// Clock pins for APA102: 13, 14

STM32 (BluePill)¶

#define DATA_PIN PA7

// Available pins: Most GPIO pins
// SPI for APA102: PA5 (SCK), PA7 (MOSI)

Raspberry Pi Pico (RP2040)¶

#define DATA_PIN 16

// GPIO pins 0-29 available
// PIO-based output provides excellent performance

Calcolo della Memoria¶

Ogni LED utilizza 3 byte (RGB):

Example: 500 LEDs = 1500 bytes

Arduino Uno: 2KB RAM total
- System: ~500 bytes
- Your code: ~500 bytes
- LEDs: ~1000 bytes (333 LEDs max)

Best Practice¶

Selezione dei Pin¶

  1. Evitare pin di boot/strapping - Possono interferire con la programmazione

  2. Evitare pin di solo input - Alcune piattaforme hanno GPIO di solo input

  3. Controllare i livelli di tensione - Assicurarsi che le uscite a 3,3 V siano compatibili con i LED a 5 V

  4. Utilizzare periferiche hardware - RMT (ESP32), PIO (RP2040) per prestazioni ottimali

Strip Multiple¶

// Define multiple strips on different pins
CRGB strip1[LEDS_PER_STRIP];
CRGB strip2[LEDS_PER_STRIP];
CRGB strip3[LEDS_PER_STRIP];

void setup() {
    FastLED.addLeds<WS2812B, 5, GRB>(strip1, LEDS_PER_STRIP);
    FastLED.addLeds<WS2812B, 6, GRB>(strip2, LEDS_PER_STRIP);
    FastLED.addLeds<WS2812B, 7, GRB>(strip3, LEDS_PER_STRIP);
}

Spostamento del Livello¶

Per microcontrollori a 3,3 V che pilotano LED a 5 V:

  • Opzione 1: Utilizzare uno shifter di livello (74HCT245 o simile)

  • Opzione 2: Provare la connessione diretta (spesso funziona, ma non è garantito)

  • Opzione 3: Utilizzare LED RGBW (spesso più tolleranti ai segnali a 3,3 V)

Risoluzione dei problemi¶

Primo LED Errato/Sfarfallìo¶

Problema: Il primo LED mostra un colore sbagliato o sfarfalla Soluzione: Aggiungere una resistenza da 220-470 Ω sulla linea dati (vicino al microcontrollore)

Problemi di Segnale su Lunghe Distanze¶

Problema: I LED falliscono dopo una certa distanza Soluzione:

  • Mantenere il cavo dati corto (idealmente < 15 cm)

  • Utilizzare un variatore di livello per tratte più lunghe

  • Valutare l’utilizzo di APA102 (clock + dati) per una migliore integrità del segnale

Interferenza WiFi ESP32¶

Problema: I LED si spengono durante l’attività Wi-Fi Soluzione: Utilizzare pin RMT (GPIO 2, 4, 5, 12-19, 21-23, 25-27, 32-33)
