Operazioni Comuni¶

Configurazione e Visualizzazione

FastLED.addLeds<LED_TYPE, DATA_PIN, COLOR_ORDER>(leds, NUM_LEDS);
FastLED.show();
FastLED.setBrightness(50);

Creazione di Colori

CRGB color = CRGB(255, 0, 0);    // RGB
CHSV color = CHSV(0, 255, 255);  // HSV

Operazioni Sugli Array

fill_solid(leds, NUM_LEDS, CRGB::Red);
fadeToBlackBy(leds, NUM_LEDS, 20);
blur1d(leds, NUM_LEDS, 50);

Supporto Piattaforme¶

FastLED supporta un’ampia gamma di microcontrollori:

  • Arduino (Uno, Mega, Leonardo, ecc.)

  • ESP32 / ESP8266

  • Teensy (3.x, 4.x)

  • STM32

  • Raspberry Pi Pico (RP2040)

  • E molti altri!

Vedere Configurazioni dei Pin per dettagli specifici sulla piattaforma.

Supporto chipset LED¶

FastLED supporta numerosi chipset LED, tra cui:

  • WS2812B (NeoPixel)

  • APA102 (DotStar)

  • SK6812

  • WS2813

  • E molti altri!

Consultare Tipi di LED per un elenco completo ed esempi di utilizzo.
