Guida completa ai chipset LED supportati da FastLED.

Livello di Difficoltà: ⭐ Tutti i Livelli

Prerequisiti: Nessuno

  • Esempi di codice per ciascun chipset con la corretta configurazione di LED_TYPE e COLOR_ORDER per un utilizzo immediato tramite copia e incolla

  • Guida alla selezione del chipset che confronta costi, velocità, affidabilità e casi d’uso (quando utilizzare WS2812B vs APA102 vs SK6812 vs WS2813)

  • Guida alla risoluzione dei problemi relativi all’ordine dei colori, problemi al primo LED, guasti parziali e sfarfallìo casuale

Esempi di Codice per Tipo¶

WS2812B / NeoPixel¶

#define LED_TYPE WS2812B
#define COLOR_ORDER GRB
FastLED.addLeds<LED_TYPE, DATA_PIN, COLOR_ORDER>(leds, NUM_LEDS);

Caratteristiche:

  • Singolo cavo dati (senza clock)

  • 800 Velocità dati KHz

  • Il più comune e ampiamente disponibile

  • Adatto alla maggior parte delle applicazioni

  • Economico

APA102 / DotStar¶

#define LED_TYPE APA102
#define COLOR_ORDER BGR
FastLED.addLeds<LED_TYPE, DATA_PIN, CLOCK_PIN, COLOR_ORDER>(leds, NUM_LEDS);

Caratteristiche:

  • Linee dati e clock separate

  • Frequenze di refresh molto più veloci (fino a 20 MHz)

  • Migliore precisione del colore

  • Adatto per cavi lunghi

  • Più costoso del WS2812B

SK6812 (RGBW)¶

// Note: FastLED doesn't natively support RGBW, use workaround:
#define LED_TYPE SK6812
#define COLOR_ORDER GRB
FastLED.addLeds<LED_TYPE, DATA_PIN, COLOR_ORDER>(leds, NUM_LEDS);

Caratteristiche:

  • Simile al WS2812B

  • Disponibile variante RGBW (aggiunge il canale bianco)

  • Ideale per applicazioni a luce bianca

  • FastLED funziona solo come RGB

WS2813¶

#define LED_TYPE WS2813
#define COLOR_ORDER GRB
FastLED.addLeds<LED_TYPE, DATA_PIN, COLOR_ORDER>(leds, NUM_LEDS);

Caratteristiche:

  • Linea dati di backup per affidabilità

  • Compatibile con il protocollo WS2812B

  • Più robusto del WS2812B

  • Un singolo guasto del LED non interrompe la catena

Riferimento per l’Ordine dei Colori¶

Diversi tipi di LED utilizzano ordini di colore diversi:

// Common orders:
GRB  // WS2812B, WS2813, most strips
RGB  // Some WS2811, APA106
BGR  // APA102, SK9822
BRG  // Rare

Test dell’Ordine dei Colori¶

void testColorOrder() {
    leds[0] = CRGB(255, 0, 0);  // Should show RED
    leds[1] = CRGB(0, 255, 0);  // Should show GREEN
    leds[2] = CRGB(0, 0, 255);  // Should show BLUE
    FastLED.show();

    // If wrong, try different COLOR_ORDER in setup
}

Scelta del tipo di LED¶

Utilizzare WS2812B quando:¶

  • È necessaria un’opzione economica

  • È preferibile un singolo cavo dati

  • La velocità non è critica (aggiornamento <400 Hz)

  • Più comune e compatibile

Pro:

  • Economico

  • Ampiamente disponibile

  • Semplicità del singolo cavo

  • Buon supporto della community

Contro:

  • Sensibile al timing

  • Frequenze di aggiornamento più lente

  • Meno affidabile su lunghe distanze

Utilizzare APA102 quando:¶

  • Sono necessarie frequenze di aggiornamento più elevate (>400 Hz)

  • Si desidera una migliore precisione del colore

  • Sono disponibili pin SPI

  • Sono necessari cavi più lunghi

Pro:

  • Aggiornamento molto rapido

  • Linea di clock separata (più affidabile)

  • Migliore integrità del segnale

  • Non è critico per il timing

Contro:

  • Più costoso

  • Richiede 2 fili (dati + clock)

  • Utilizza più pin sul microcontrollore

Utilizzare SK6812 quando:¶

  • È necessaria la funzionalità RGBW (bianco puro)

  • Si desidera la compatibilità con WS2812B

  • Lavorare con display a luce bianca

Pro:

  • Varianti RGBW disponibili

  • Compatibile con il codice WS2812B

  • Buona qualità della luce bianca

Contro:

  • Supporto limitato FastLED RGBW

  • Leggermente più costoso di WS2812B

Utilizzare WS2813 quando:¶

  • È necessaria affidabilità in installazioni lunghe

  • È necessaria la funzionalità di linea dati di backup

  • Si è preoccupati per i guasti di singoli LED

Pro:

  • Linea dati di backup (più robusta)

  • Compatibile con WS2812B

  • La catena continua in caso di guasto del LED

Contro:

  • Più costoso del WS2812B

  • Resta sensibile alla temporizzazione come WS2812B

Specifiche Tecniche¶

WS2812B¶

Data Rate:        800 KHz
Color Depth:      8-bit per channel (24-bit RGB)
Voltage:          5V (±0.5V)
Current per LED:  ~60mA at full white
Protocol:         Single wire, timing-based
Timing Tolerance: ±150ns

APA102¶

Data Rate:        Variable, up to 20 MHz
Color Depth:      8-bit per channel + 5-bit global brightness
Voltage:          5V (±0.5V)
Current per LED:  ~20mA at full white
Protocol:         SPI-like (clock + data)
Timing Tolerance: Not critical (clocked)

SK6812¶

Data Rate:        800 KHz
Color Depth:      8-bit per channel (24-bit RGB or 32-bit RGBW)
Voltage:          5V (±0.5V)
Current per LED:  ~60mA at full white (RGB), ~80mA (RGBW)
Protocol:         Single wire, timing-based
Timing Tolerance: ±150ns

Linee guida per il Cablaggio¶

LED a filo singolo (WS2812B, SK6812, WS2813)¶

Microcontroller GPIO ──[220Ω resistor]──> LED Strip DATA
Microcontroller GND  ───────────────────> LED Strip GND
Power Supply 5V      ───────────────────> LED Strip VCC
Power Supply GND     ───────────────────> LED Strip GND + MCU GND

LED Clock + Dati (APA102, SK9822)¶

Microcontroller MOSI ──[220Ω resistor]──> LED Strip DATA
Microcontroller SCK  ──[220Ω resistor]──> LED Strip CLOCK
Microcontroller GND  ───────────────────> LED Strip GND
Power Supply 5V      ───────────────────> LED Strip VCC
Power Supply GND     ───────────────────> LED Strip GND + MCU GND

Problemi Comuni¶

Colori Visualizzati Errati¶

Problema: I LED mostrano colori errati Soluzione: Provare diversi valori di COLOR_ORDER (GRB, RGB, BGR, ecc.)

Il primo LED lampeggia o è errato¶

Problema: Il primo LED non è affidabile Soluzione: Aggiungere una resistenza da 220-470Ω sulla linea dati vicino al microcontrollore

I LED funzionano parzialmente¶

Problema: I primi N LED funzionano, gli altri no Soluzione:

  • Controllare la capacità di alimentazione

  • Controllare che non vi siano LED danneggiati al punto di interruzione

  • Aggiungere potenza ogni 60-100 LED

Sfarfallìo Casuale¶

Problema: I LED sfarfallano in modo casuale Soluzione:

  • Aggiungere un condensatore da 1000 µF all’alimentatore

  • Assicurarsi che i collegamenti di terra siano solidi

  • Controllare la capacità di alimentazione
