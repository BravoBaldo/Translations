Animazioni Semplici¶

Livello di Difficoltà: ⭐ Principiante Tempo di Completamento: 20-25 minuti Prerequisiti: Colori Pieni, Concetti di Temporizzazione

Si imparerà:

  • Come creare animazioni con dissolvenza in entrata/uscita fluide utilizzando il controllo della luminosità

  • La potenza delle variabili statiche per mantenere lo stato dell’animazione

  • La differenza tra il controllo della luminosità globale e quello per singolo LED

  • Come controllare la velocità dell’animazione con temporizzazione e ritardo

  • Come creare variazioni parametrizzando le funzioni di animazione

Imparare a creare effetti fluidi e dinamici animando luminosità e colore nel tempo. L’effetto dissolvenza in entrata/uscita è una delle animazioni più fondamentali nella programmazione LED.

Effetto Fade In/Out¶

Questo effetto classico dissolve gradualmente i LED da spenti alla massima luminosità e viceversa.

void fadeInOut() {
    static uint8_t brightness = 0;
    static int8_t direction = 1;

    brightness += direction;
    if (brightness == 0 || brightness == 255) {
        direction = -direction;
    }

    fill_solid(leds, NUM_LEDS, CRGB::Purple);
    FastLED.setBrightness(brightness);
    FastLED.show();
}

Come Funziona¶

  1. Variabili Statiche: brightness e direction persistono tra le chiamate di funzione

  2. Controllo Direzione: direction è 1 (crescente) o -1 (decrescente)

  3. Rilevamento dei Confini: Quando la luminosità raggiunge 0 o 255, la direzione si inverte

  4. Applicazione Luminosità: setBrightness() ha effetto su tutti i LED a livello globale

Concetti Chiave¶

Variabili Statiche¶

Le variabili statiche mantengono i loro valori tra le chiamate di funzione:

static uint8_t brightness = 0;  // Initialized once, persists

enza static, la variabile verrebbe reimpostata a 0 ogni volta che la funzione viene chiamata.

Luminosità Globale vs. Per Singolo LED¶

// Global brightness (affects all LEDs)
FastLED.setBrightness(brightness);

// Per-LED brightness (using HSV)
for (int i = 0; i < NUM_LEDS; i++) {
    leds[i] = CHSV(160, 255, brightness);
}

Controllo dei Tempi¶

Controllare la velocità dell’animazione richiamando la funzione a velocità diverse:

void loop() {
    fadeInOut();
    delay(20);  // Faster animation

    // Or use timing macros
    EVERY_N_MILLISECONDS(20) {
        fadeInOut();
    }
}

Esempio Completo¶

#include <FastLED.h>

#define LED_PIN     5
#define NUM_LEDS    60
#define LED_TYPE    WS2812B
#define COLOR_ORDER GRB

CRGB leds[NUM_LEDS];

void setup() {
    FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS);
    FastLED.setBrightness(50);
}

void fadeInOut() {
    static uint8_t brightness = 0;
    static int8_t direction = 1;

    brightness += direction;
    if (brightness == 0 || brightness == 255) {
        direction = -direction;
    }

    fill_solid(leds, NUM_LEDS, CRGB::Purple);
    FastLED.setBrightness(brightness);
    FastLED.show();
}

void loop() {
    fadeInOut();
    delay(10);  // Control speed here
}

Dissolvenza per singolo LED¶

Per un maggiore controllo, sfumare i singoli LED:

void fadeInOutPerLED() {
    static uint8_t brightness = 0;
    static int8_t direction = 1;

    brightness += direction;
    if (brightness == 0 || brightness == 255) {
        direction = -direction;
    }

    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = CHSV(160, 255, brightness);
    }
    FastLED.show();
}

Velocità Variabile¶

Regolare la velocità della dissolvenza in modo dinamico:

void fadeInOutSpeed(uint8_t speed) {
    static uint8_t brightness = 0;
    static int8_t direction = speed;

    brightness += direction;
    if (brightness == 0 || brightness >= 255) {
        direction = -direction;
    }

    fill_solid(leds, NUM_LEDS, CRGB::Blue);
    FastLED.setBrightness(brightness);
    FastLED.show();
}

Suggerimenti¶

  • Usare delay() o macro di temporizzazione per controllare la velocità dell’animazione

  • Le variabili statiche sono essenziali per mantenere lo stato tra le chiamate

  • La luminosità globale è più efficiente delle variazioni di luminosità per singolo LED

  • Sperimenta con diversi valori di incremento per dissolvenze più veloci/lente

  • Combinare con il ciclo di colori per effetti più complessi
