Effetti Arcobaleno¶

Livello di Difficoltà: ⭐ Principiante Tempo di Completamento: 30-35 minuti Prerequisiti:

  • Colori Pieni - Comprensione delle funzioni di riempimento e delle basi del colore

  • Animazioni - Utilizzo di variabili statiche per l’animazione

  • Teoria del Colore - Spazi colore RGB vs HSV

Si imparerà:

  • Come usare fill_rainbow() per creare sfumature arcobaleno uniformi sulla striscia LED

  • Perché lo spazio colore HSV semplifica notevolmente gli effetti arcobaleno rispetto a RGB

  • Come animare gli arcobaleni ciclando il valore di tonalità iniziale

  • Come controllare la densità, la velocità e la direzione dell’arcobaleno con i parametri

  • Tecniche avanzate per l’arcobaleno, tra cui mirroring, chunking, effetti di respirazione e animazioni bidirezionali

Gli effetti arcobaleno mettono in mostra la potenza dello spazio colore HSV per creare transizioni di colore fluide e naturali. Questi pattern sono visivamente sorprendenti e dimostrano le tecniche essenziali per il ciclo dei colori.

Arcobaleno Statico¶

Creare un arcobaleno che si estende sull’intera striscia LED:

void rainbow() {
    fill_rainbow(leds, NUM_LEDS, 0, 255 / NUM_LEDS);
}

Parametri¶

  • leds: La matrice LED

  • NUM_LEDS: Numero di LED da riempire

  • 0: Tonalità iniziale (0-255)

  • 255 / NUM_LEDS: Incremento di tonalità per LED

Questo distribuisce tutti i 256 valori di tonalità uniformemente sulla striscia.

Arcobaleno in Movimento¶

Animare l’arcobaleno alternando la tonalità iniziale:

void movingRainbow() {
    static uint8_t hue = 0;
    fill_rainbow(leds, NUM_LEDS, hue, 255 / NUM_LEDS);
    hue++;
}

L’arcobaleno sembra muoversi lungo la striscia man mano che la tonalità iniziale aumenta a ogni fotogramma.

Esempio Completo¶

#include <FastLED.h>

#define LED_PIN     5
#define NUM_LEDS    60
#define LED_TYPE    WS2812B
#define COLOR_ORDER GRB

CRGB leds[NUM_LEDS];

void setup() {
    FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS);
    FastLED.setBrightness(50);
}

void movingRainbow() {
    static uint8_t hue = 0;
    fill_rainbow(leds, NUM_LEDS, hue, 255 / NUM_LEDS);
    hue++;
}

void loop() {
    movingRainbow();
    FastLED.show();
    delay(20);
}

Capire lo Spazio Colore HSV¶

HSV utilizza tre componenti:

  • Hue (0-255): [Tonalità] Colore attorno alla ruota dei colori

  • Saturazione (0-255): Intensità del colore (255 = vivido, 0 = bianco)

  • Valore (0-255): Luminosità (255 = brillante, 0 = spento)

CHSV color = CHSV(hue, 255, 255);  // Full saturation and brightness

Valori di Tonalità¶

  • 0: Rosso

  • 32: Arancione

  • 64: Giallo

  • 96: Verde

  • 128: Ciano

  • 160: Blu

  • 192: Viola

  • 224: Rosa

  • 255: Rosso (ri-avvolto)

Varianti¶

Arcobaleno più Stretto¶

Creare più cicli di arcobaleno lungo la striscia:

void tightRainbow() {
    static uint8_t hue = 0;
    fill_rainbow(leds, NUM_LEDS, hue, 5);  // Larger delta = tighter rainbow
    hue++;
}

Direzione Inversa¶

Muovere l’arcobaleno all’indietro:

void reverseRainbow() {
    static uint8_t hue = 0;
    fill_rainbow(leds, NUM_LEDS, hue, 255 / NUM_LEDS);
    hue--;  // Decrement instead of increment
}

Velocità Variabile¶

Controllare la velocità di animazione dell’arcobaleno:

void speedRainbow(uint8_t speed) {
    static uint8_t hue = 0;
    fill_rainbow(leds, NUM_LEDS, hue, 255 / NUM_LEDS);
    hue += speed;  // Higher speed = faster movement
}

void loop() {
    speedRainbow(3);  // 3x faster than normal
    FastLED.show();
    delay(20);
}

Arcobaleno Parziale¶

Riempire solo una parte della striscia:

void partialRainbow() {
    static uint8_t hue = 0;

    // Rainbow on first half
    fill_rainbow(&leds[0], NUM_LEDS / 2, hue, 10);

    // Solid color on second half
    fill_solid(&leds[NUM_LEDS / 2], NUM_LEDS / 2, CRGB::Black);

    hue++;
}

Arcobaleno Speculare¶

Creare un effetto arcobaleno speculare:

void mirrorRainbow() {
    static uint8_t hue = 0;

    int half = NUM_LEDS / 2;
    fill_rainbow(&leds[0], half, hue, 255 / half);

    // Mirror to second half
    for (int i = 0; i < half; i++) {
        leds[NUM_LEDS - 1 - i] = leds[i];
    }

    hue++;
}

Tecniche Avanzate¶

Arcobaleno che Respira¶

Combinare l’arcobaleno con la luminosità pulsante:

void breathingRainbow() {
    static uint8_t hue = 0;

    // Create rainbow
    fill_rainbow(leds, NUM_LEDS, hue, 255 / NUM_LEDS);

    // Pulse brightness
    uint8_t brightness = beatsin8(12, 50, 255);  // 12 BPM, 50-255 range
    FastLED.setBrightness(brightness);

    hue++;
}

Arcobaleno a Blocchi¶

Crea blocchi di arcobaleno discreti:

void chunkRainbow() {
    static uint8_t hue = 0;
    int chunkSize = 5;

    for (int i = 0; i < NUM_LEDS; i += chunkSize) {
        fill_solid(&leds[i], chunkSize, CHSV(hue + (i * 10), 255, 255));
    }

    hue++;
}

Arcobaleno a Doppia Direzione¶

Due arcobaleni che si muovono in direzioni opposte:

void dualRainbow() {
    static uint8_t hue1 = 0;
    static uint8_t hue2 = 128;  // Offset by half

    // First rainbow
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = CHSV(hue1 + (i * 4), 255, 128);
    }

    // Second rainbow (additive)
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] += CHSV(hue2 - (i * 4), 255, 128);
    }

    hue1++;
    hue2--;
}

Suggerimenti¶

  • Usare fill_rainbow() per una generazione efficiente di arcobaleni

  • HSV rende il ciclo di colori molto più semplice di RGB

  • Regolare il delta di tonalità (4° parametro) per controllare la compattezza dell’arcobaleno

  • Combinarlo con altri effetti come dissolvenza o scie per una maggiore varietà

  • Usare beatsin8() per variazioni di velocità fluide e automatiche

Perché HSV per gli Arcobaleni?¶

L’arcobaleno RGB richiede calcoli complessi:

// RGB rainbow (complex)
if (hue < 85) {
    r = hue * 3;
    g = 255 - hue * 3;
    b = 0;
} // ... more cases

L’arcobaleno HSV è semplice:

// HSV rainbow (simple)
CHSV color = CHSV(hue, 255, 255);
hue++;
