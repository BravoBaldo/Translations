Sequenze e Scanner¶

Livello di Difficoltà: ⭐ Principiante Tempo di Completamento: 25-30 minuti Prerequisiti: Animazioni, Concetti di Temporizzazione, Colori Pieni

Si imparerà:

  • Come creare movimento lungo la striscia LED utilizzando il tracciamento della posizione

  • La differenza tra effetti di rimbalzo (bidirezionali) e inseguimento (unidirezionali)

  • Come usare fadeToBlackBy() per creare effetti di scia dietro i LED in movimento

  • Come implementare il rilevamento dei confini e l’inversione di direzione per i pattern di rimbalzo

  • Come creare varianti come scanner multipli, cambi di colore e larghezza variabile

Gli effetti “chase” [inseguimento] e scansione creano l’illusione di movimento lungo la striscia LED. Il classico scanner “Cylon” o “Knight Rider” è un esempio iconico che insegna le tecniche di animazione essenziali.

Effetto Nightrider / Cylon¶

L’effetto Cylon è caratterizzato da un LED che rimbalza avanti e indietro con una scia in dissolvenza:

void cylon() {
    static uint8_t pos = 0;
    static int8_t direction = 1;

    // Fade all LEDs
    fadeToBlackBy(leds, NUM_LEDS, 20);

    // Set current position
    leds[pos] = CRGB::Red;

    // Move position
    pos += direction;
    if (pos == 0 || pos == NUM_LEDS - 1) {
        direction = -direction;
    }
}

Come Funziona¶

  1. Tracciamento della Posizione: pos traccia la posizione corrente del LED

  2. Controllo della Direzione: direction determina il movimento in avanti (1) o indietro (-1)

  3. Effetto Scia: fadeToBlackBy() crea una coda in dissolvenza

  4. Rilevamento dei Limiti: Al raggiungimento di una delle estremità, la direzione si inverte

  5. Illuminazione LED: La posizione corrente viene impostata sul colore desiderato

Concetti Chiave¶

Effetti scia con fadeToBlackBy¶

fadeToBlackBy(leds, NUM_LEDS, 20);

Questa funzione sfuma tutti i LED verso il nero del valore specificato (0-255):

  • 20: Dissolvenza più lenta, scia più lunga

  • 100: Dissolvenza più veloce, scia più corta

  • 255: Nessuna scia (spegnimento immediato)

Gestione della Posizione¶

Tracciare e aggiornare la posizione con i limiti:

pos += direction;
if (pos == 0 || pos == NUM_LEDS - 1) {
    direction = -direction;
}

Questo crea un effetto di rimbalzo alle estremità delle strisce.

Esempio Completo¶

#include <FastLED.h>

#define LED_PIN     5
#define NUM_LEDS    60
#define LED_TYPE    WS2812B
#define COLOR_ORDER GRB

CRGB leds[NUM_LEDS];

void setup() {
    FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS);
    FastLED.setBrightness(50);
}

void cylon() {
    static uint8_t pos = 0;
    static int8_t direction = 1;

    // Fade all LEDs
    fadeToBlackBy(leds, NUM_LEDS, 20);

    // Set current position
    leds[pos] = CRGB::Red;

    // Move position
    pos += direction;
    if (pos == 0 || pos == NUM_LEDS - 1) {
        direction = -direction;
    }
}

void loop() {
    cylon();
    FastLED.show();
    delay(30);  // Control speed
}

Varianti¶

Punti Multipli¶

Creare più punti di scansione:

void multiCylon() {
    static uint8_t pos1 = 0;
    static uint8_t pos2 = NUM_LEDS / 2;
    static int8_t direction1 = 1;
    static int8_t direction2 = -1;

    fadeToBlackBy(leds, NUM_LEDS, 20);

    // First scanner
    leds[pos1] = CRGB::Red;
    pos1 += direction1;
    if (pos1 == 0 || pos1 == NUM_LEDS - 1) {
        direction1 = -direction1;
    }

    // Second scanner
    leds[pos2] = CRGB::Blue;
    pos2 += direction2;
    if (pos2 == 0 || pos2 == NUM_LEDS - 1) {
        direction2 = -direction2;
    }
}

Scanner che cambia colore¶

Ciclare i colori durante la scansione:

void colorCylon() {
    static uint8_t pos = 0;
    static int8_t direction = 1;
    static uint8_t hue = 0;

    fadeToBlackBy(leds, NUM_LEDS, 20);

    leds[pos] = CHSV(hue, 255, 255);

    pos += direction;
    if (pos == 0 || pos == NUM_LEDS - 1) {
        direction = -direction;
        hue += 32;  // Change color at each bounce
    }
}

Inseguimento Semplice (Senso Unico)¶

Un punto che si muove continuamente in una direzione:

void chase() {
    static uint8_t pos = 0;

    fadeToBlackBy(leds, NUM_LEDS, 30);
    leds[pos] = CRGB::Green;

    pos++;
    if (pos >= NUM_LEDS) {
        pos = 0;
    }
}

Scanner più Ampio¶

Creare un effetto di scansione più ampio:

void wideCylon() {
    static uint8_t pos = 0;
    static int8_t direction = 1;

    fadeToBlackBy(leds, NUM_LEDS, 20);

    // Light up multiple LEDs for width
    int width = 5;
    for (int i = 0; i < width; i++) {
        int ledPos = pos + i - (width / 2);
        if (ledPos >= 0 && ledPos < NUM_LEDS) {
            leds[ledPos] = CRGB::Red;
        }
    }

    pos += direction;
    if (pos == 0 || pos == NUM_LEDS - 1) {
        direction = -direction;
    }
}

Tecniche Avanzate¶

Velocità Variabile¶

Modificare la velocità in base alla posizione:

void acceleratingCylon() {
    static uint8_t pos = 0;
    static int8_t direction = 1;
    static uint8_t speed = 1;

    fadeToBlackBy(leds, NUM_LEDS, 20);
    leds[pos] = CRGB::Red;

    // Calculate speed based on distance from center
    uint8_t distFromCenter = abs(pos - NUM_LEDS / 2);
    speed = map(distFromCenter, 0, NUM_LEDS / 2, 1, 3);

    pos += direction * speed;
    if (pos <= 0 || pos >= NUM_LEDS - 1) {
        direction = -direction;
        pos = constrain(pos, 0, NUM_LEDS - 1);
    }
}

Suggerimenti¶

  • Regolare il valore di fadeToBlackBy() per controllare la lunghezza della traccia (20-50 ms è un valore ottimale)

  • Usare delay() per controllare la velocità di scansione (20-50 ms è tipico)

  • Sperimentare con colori diversi per creare atmosfere diverse

  • Più scanner possono creare interessanti effetti di collisione

  • Provare a usare blur1d() invece di fadeToBlackBy() per tracce più fluide
