Colori Pieni¶

Livello di Difficoltà: ⭐ Principiante Tempo di completamento: 15-20 minuti Prerequisiti: Concetti Fondamentali, Primo Esempio

Si imparerà:

  • Come riempire l’intera striscia LED con un singolo colore pieno

  • La differenza tra gli spazi colore RGB e HSV e quando utilizzarli

  • Come utilizzare le efficienti funzioni di riempimento di FastLED invece dei loop manuali

  • Come riempire sezioni specifiche della striscia LED con colori diversi

  • Costanti di colore denominate per un codice leggibile e manutenibile

I colori pieni sono la base del controllo LED. Questo pattern mostra come riempire la striscia LED con un singolo colore utilizzando le efficienti funzioni di riempimento di FastLED.

Utilizzo di Base¶

Riempire l’Intera Striscia¶

Riempire tutti i LED con un singolo colore:

// Fill entire strip
fill_solid(leds, NUM_LEDS, CRGB::Blue);

Riempire un Intervallo¶

Riempire una sezione specifica della striscia:

// Fill range
fill_solid(&leds[10], 20, CRGB::Green);  // LEDs 10-29

Questo riempie 20 LED a partire dall’indice 10, controllando efficacemente i LED dal 10 al 29.

Riempire con HSV¶

Utilizzare lo spazio colore HSV per una selezione dei colori più intuitiva:

// Fill with HSV
fill_solid(leds, NUM_LEDS, CHSV(160, 255, 255));

Informazioni sugli Spazi Colore¶

Colori RGB¶

RGB (Rosso, Verde, Blu) utilizza tre canali da 0 a 255:

CRGB color = CRGB(255, 0, 0);      // Red
CRGB color = CRGB(0, 255, 0);      // Green
CRGB color = CRGB(0, 0, 255);      // Blue
CRGB color = CRGB(255, 255, 255);  // White

Colori HSV¶

HSV (Tonalità, Saturazione, Valore) è spesso più intuitivo:

CHSV hsv = CHSV(0, 255, 255);      // Red
CHSV hsv = CHSV(96, 255, 255);     // Green
CHSV hsv = CHSV(160, 255, 255);    // Blue

// Convert HSV to RGB (automatic)
leds[0] = hsv;

Perché usare HSV?

  • Più facile creare transizioni di colore fluide (basta incrementare la tonalità)

  • Naturale per effetti arcobaleno

  • Controllo intuitivo della luminosità senza cambiare colore

Colori con Nome¶

FastLED fornisce pratici colori con nome:

leds[0] = CRGB::Red;
leds[1] = CRGB::Green;
leds[2] = CRGB::Blue;
leds[3] = CRGB::White;
leds[4] = CRGB::Yellow;
leds[5] = CRGB::Purple;
leds[6] = CRGB::Cyan;
leds[7] = CRGB::Black;  // Off

Esempio Completo¶

#include <FastLED.h>

#define LED_PIN     5
#define NUM_LEDS    60
#define LED_TYPE    WS2812B
#define COLOR_ORDER GRB

CRGB leds[NUM_LEDS];

void setup() {
    FastLED.addLeds<LED_TYPE, LED_PIN, COLOR_ORDER>(leds, NUM_LEDS);
    FastLED.setBrightness(50);
}

void loop() {
    // Cycle through different solid colors
    fill_solid(leds, NUM_LEDS, CRGB::Red);
    FastLED.show();
    delay(1000);

    fill_solid(leds, NUM_LEDS, CRGB::Green);
    FastLED.show();
    delay(1000);

    fill_solid(leds, NUM_LEDS, CRGB::Blue);
    FastLED.show();
    delay(1000);

    // Fill different sections
    fill_solid(&leds[0], 20, CRGB::Red);
    fill_solid(&leds[20], 20, CRGB::Green);
    fill_solid(&leds[40], 20, CRGB::Blue);
    FastLED.show();
    delay(1000);
}

Suggerimenti¶

  • Usare fill_solid() invece di loop manuali per prestazioni migliori

  • Lo spazio colore HSV semplifica la creazione di colori fluidi transizioni

  • Usare FastLED.clear() come scorciatoia per il riempimento con il nero (off)

  • Colori con nome come CRGB::Red sono più leggibili di CRGB(255, 0, 0)

Passaggi successivi¶

Una volta acquisita familiarità con i colori pieni, passare ad Animazioni per imparare a creare effetti dinamici.
