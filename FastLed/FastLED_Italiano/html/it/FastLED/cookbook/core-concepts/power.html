Gestire il consumo energetico in modo sicuro nei progetti LED.

Requisiti di Corrente¶

Regola Pratica¶

60mA per LED a piena luminosità bianca

Questo è il massimo assorbimento di corrente quando tutti e tre i canali colore (R, G, B) sono a 255.

Calcolo del Fabbisogno Energetico¶

Total current = Number of LEDs × 60mA

Examples:
- 30 LEDs:  30 × 60mA = 1.8A  (recommend 2.5A supply)
- 60 LEDs:  60 × 60mA = 3.6A  (recommend 5A supply)
- 100 LEDs: 100 × 60mA = 6.0A (recommend 8A supply)
- 200 LEDs: 200 × 60mA = 12A  (recommend 15A supply)

Aggiungere sempre un margine del 20-30% per tenere conto dell’invecchiamento dell’alimentatore e della regolazione della tensione.

Riduzione del Consumo Energetico¶

Metodo 1: Ridurre la Luminosità¶

void setup() {
    FastLED.addLeds<WS2812B, DATA_PIN>(leds, NUM_LEDS);
    FastLED.setBrightness(50);  // ~20% brightness = ~20% power
}

La luminosità varia linearmente con il consumo energetico.

Metodo 2: Impostare il Limite di Potenza¶

FastLED può limitare automaticamente il consumo energetico:

void setup() {
    FastLED.addLeds<WS2812B, DATA_PIN>(leds, NUM_LEDS);

    // Limit to 5V, 2000mA (2A)
    FastLED.setMaxPowerInVoltsAndMilliamps(5, 2000);
}

Questo riduce automaticamente la luminosità quando necessario per rimanere entro i limiti di potenza.

Metodo 3: Limitare la Complessità del Pattern¶

// HIGH POWER: All LEDs full white
fill_solid(leds, NUM_LEDS, CRGB::White);  // 60mA per LED

// MEDIUM POWER: Single color
fill_solid(leds, NUM_LEDS, CRGB::Red);    // ~20mA per LED

// LOW POWER: Dim colors
fill_solid(leds, NUM_LEDS, CRGB(50, 50, 50));  // ~10mA per LED

Metodo 4: Utilizzare Meno LED alla Massima Luminosità¶

void chase() {
    // Only 1 LED is bright at a time
    FastLED.clear();
    leds[position] = CRGB::White;
    FastLED.show();
}

Consumo Energetico Reale¶

La maggior parte dei pattern utilizza il 30-50% della potenza massima perché:

  • Non tutti i LED sono accesi contemporaneamente

  • Non tutti i LED sono alla massima luminosità

  • I colori non sono solitamente bianco puro

Iniezione di Potenza¶

Per strisce con più di 100 LED, iniettare potenza in più punti:

[Power Supply]
     |
     +---> Strip Beginning (VCC, GND)
     |
     +---> Strip Middle (VCC, GND)
     |
     +---> Strip End (VCC, GND)

Perché? La caduta di tensione lungo la striscia causa:

  • LED dimmerabili all’estremità

  • Spostamento del colore (tensione insufficiente per tutti i canali)

  • Funzionamento instabile

Caduta di Tensione¶

Le strisce LED hanno una resistenza. A distanza, cali di tensione:

At start of strip:    5.0V
After 60 LEDs:        4.7V
After 100 LEDs:       4.4V  (too low - colors shift)
After 150 LEDs:       4.0V  (unreliable)

Soluzione: iniettare potenza ogni 60-100 LED.

Esempio di Iniezione di Potenza¶

// For 200 LED strip with power injection at LED 0, 100, 200

void setup() {
    FastLED.addLeds<WS2812B, DATA_PIN>(leds, NUM_LEDS);

    // Still limit total power
    FastLED.setMaxPowerInVoltsAndMilliamps(5, 10000);  // 10A total

    // Wire: Power supply to strip at positions 0, 100, 200
}

Condensatori¶

Condensatore di Alimentazione¶

Aggiungere sempre un condensatore di grandi dimensioni all’alimentatore:

1000µF (or larger) capacitor between 5V and GND

  • Attenuare le fluttuazioni di tensione

  • Proteggere dai picchi di potenza durante gli aggiornamenti dei LED

  • Essenziale per un funzionamento stabile

Condensatori per Sezione¶

Per installazioni di grandi dimensioni, aggiungere condensatori in ogni punto di iniezione di potenza:

470-1000µF capacitor at each power connection

Considerazioni sulla Sicurezza¶

Non Alimentare i LED dal Microcontrollore¶

// DANGEROUS: Arduino 5V pin can supply ~500mA max
// This will damage the Arduino or crash it

// SAFE: Use external power supply

Mai alimentare più di ~5-10 LED dai pin di alimentazione del microcontrollore.

Massa In Comune¶

Critico: Microcontrollore e alimentatore LED devono condividere la massa:

[Power Supply GND] ---+--- [LED Strip GND]
                      |
                      +--- [Microcontroller GND]

Senza massa in comune:

  • Comportamento irregolare dei LED

  • Danneggiamento dei dati

  • Potenziali danni ai componenti

Misurazione della Potenza¶

Utilizzo di un Multimetro¶

  1. Impostare il multimetro in modalità corrente continua (intervallo 10 A)

  2. Collegare in serie tra alimentatore e striscia LED

  3. Eseguire il pattern

  4. Leggere l’assorbimento di corrente effettivo

Stimare in codice¶

FastLED può stimare l’assorbimento di potenza:

void setup() {
    FastLED.setMaxPowerInVoltsAndMilliamps(5, 2000);
}

void loop() {
    updateLEDs();
    FastLED.show();

    // Check estimated power usage
    // (requires power calculation enabled)
}

Best Practice¶

Iniziare in Modo Conservativo¶

void setup() {
    FastLED.addLeds<WS2812B, DATA_PIN>(leds, NUM_LEDS);

    // Start with low brightness while testing
    FastLED.setBrightness(30);

    // Set power limit
    FastLED.setMaxPowerInVoltsAndMilliamps(5, 2000);
}

Aumentare Gradualmente¶

  1. Testare prima con 10 LED

  2. Verificare che l’alimentatore possa gestire la corrente

  3. Aggiungere altri LED in sezioni

  4. Monitorare la tensione all’estremità della striscia

  5. Aggiungere l’iniezione di potenza se necessario

Monitorare la Temperatura¶

Alimentatori e strisce LED generano calore:

  • L’alimentatore deve essere caldo, non bollente

  • La striscia LED deve essere toccabile

  • Se troppo calda, ridurre la luminosità o la corrente

Esempio di Configurazione Power-Safe¶

#define LED_PIN     5
#define NUM_LEDS    100
#define MAX_POWER_MILLIAMPS 4000  // 4A power supply

CRGB leds[NUM_LEDS];

void setup() {
    FastLED.addLeds<WS2812B, LED_PIN, GRB>(leds, NUM_LEDS);

    // Set reasonable brightness
    FastLED.setBrightness(80);  // ~30% brightness

    // Enable automatic power limiting
    FastLED.setMaxPowerInVoltsAndMilliamps(5, MAX_POWER_MILLIAMPS);
}

void loop() {
    // Your pattern here
    rainbowEffect();
    FastLED.show();

    delay(20);
}

Risoluzione dei Problemi di Alimentazione¶

I LED sfarfallano o si spengono casualmente¶

  • Corrente di alimentazione insufficiente

  • Collegamenti scadenti

  • Condensatore mancante

Colori sbagliati alla fine della striscia¶

  • Calo di tensione - aggiungere iniezione di potenza

  • Tensione di alimentazione troppo bassa

Il microcontrollore si resetta¶

  • Sovraccarico dell’alimentatore

  • Massa comune mancante

  • Condensatore necessario

I primi LED hanno colori diversi¶

  • Problema con il segnale dati (non con l’alimentazione)

  • Aggiungere una resistenza sulla linea dati
