Teoria del Colore¶

Comprendere i modelli di colore RGB e HSV in FastLED.

Livello di Difficoltà: ⭐⭐ Da principiante a Intermedio Tempo di Completamento: 25-30 minuti (lettura e sperimentazione con esempi) Prerequisiti: Getting Started - Configurazione base di FastLED e primo esempio

Si imparerà:

  • Come creare colori utilizzando i valori RGB (Rosso, Verde, Blu)

  • Come utilizzare HSV (Tonalità, Saturazione, Valore) per animazioni a colori più semplici

  • Quando scegliere RGB o HSV per effetti diversi

  • Come miscelare i colori e regolare la luminosità a livello di programmazione

  • Come convertire tra modelli di colore in FastLED

Modello di Colore RGB¶

RGB (Rosso, Verde, Blu) utilizza tre canali, ciascuno con valori compresi tra 0 e 255.

Creazione di colori RGB¶

CRGB color1 = CRGB(255, 0, 0);      // Pure red
CRGB color2 = CRGB(0, 255, 0);      // Pure green
CRGB color3 = CRGB(0, 0, 255);      // Pure blue
CRGB color4 = CRGB(255, 255, 255);  // White
CRGB color5 = CRGB(128, 128, 128);  // Gray
CRGB color6 = CRGB(255, 128, 0);    // Orange

Quando utilizzare RGB¶

RGB è ideale quando:

  • Si conosce esattamente il colore desiderato

  • Si lavora con colori web o valori esadecimali

  • Si necessita di un controllo preciso su ogni canale

  • Si fondono colori specifici

Modello di colore HSV¶

HSV (Tonalità, Saturazione, Valore) rappresenta i colori in modo diverso:

  • Hue (0-255): [Tonalità] Il colore stesso (posizione sulla ruota dei colori)

  • Saturazione (0-255): Intensità del colore (0 = grigio, 255 = vivido)

  • Valore (0-255): Luminosità (0 = nero, 255 = brillante)

Creazione di Colori HSV¶

CHSV hsv1 = CHSV(0, 255, 255);      // Red
CHSV hsv2 = CHSV(96, 255, 255);     // Green
CHSV hsv3 = CHSV(160, 255, 255);    // Blue
CHSV hsv4 = CHSV(64, 255, 255);     // Yellow
CHSV hsv5 = CHSV(128, 255, 255);    // Cyan

// Automatic conversion to RGB
leds[0] = hsv1;

Valori di tonalità (0-255)¶

0   = Red
32  = Orange
64  = Yellow
96  = Green
128 = Cyan
160 = Blue
192 = Purple
224 = Pink
255 = Red (wraps around)

Quando utilizzare HSV¶

HSV è ideale per:

  • Effetti arcobaleno - Incrementare semplicemente la tonalità

  • Transizioni di colore uniformi - Modificare gradualmente la tonalità

  • Controllo della luminosità - Regolare il valore senza modificare colore

  • Ciclo di colore - La tonalità si avvolge naturalmente

Confronto tra HSV e RGB¶

Creazione di un Arcobaleno¶

Con RGB (complesso):

// Must calculate each RGB component
for (int i = 0; i < NUM_LEDS; i++) {
    if (i % 6 == 0) leds[i] = CRGB(255, 0, 0);    // Red
    else if (i % 6 == 1) leds[i] = CRGB(255, 128, 0); // Orange
    else if (i % 6 == 2) leds[i] = CRGB(255, 255, 0); // Yellow
    // ... more cases
}

Con HSV (semplice):

// Just increment hue
for (int i = 0; i < NUM_LEDS; i++) {
    uint8_t hue = (i * 255) / NUM_LEDS;
    leds[i] = CHSV(hue, 255, 255);
}

Regolazione della Luminosità¶

Con RGB:

CRGB color = CRGB(200, 100, 50);
color.r = color.r * 0.5;  // Individually scale each
color.g = color.g * 0.5;
color.b = color.b * 0.5;

Con HSV:

CHSV color = CHSV(160, 255, 255);
color.v = 128;  // Simply change value
leds[0] = color;

Effetti di Saturazione¶

La saturazione controlla l’intensità del colore:

uint8_t hue = 0;  // Red

leds[0] = CHSV(hue, 255, 255);  // Vivid red
leds[1] = CHSV(hue, 192, 255);  // Slightly desaturated
leds[2] = CHSV(hue, 128, 255);  // Pinkish
leds[3] = CHSV(hue, 64, 255);   // Very pale red
leds[4] = CHSV(hue, 0, 255);    // White (no saturation)

Conversione tra RGB e HSV¶

Da HSV a RGB (Automatico)¶

CHSV hsv = CHSV(128, 255, 255);
leds[0] = hsv;  // Automatic conversion

Da RGB a HSV (manuale)¶

FastLED non fornisce la conversione da RGB a HSV. Se necessario, utilizzare HSV fin dall’inizio o implementare un proprio convertitore.

Esempi Pratici¶

Dissolvenza Uniforme del Colore¶

void colorFade() {
    static uint8_t hue = 0;

    // Fill all LEDs with current hue
    fill_solid(leds, NUM_LEDS, CHSV(hue, 255, 255));

    hue++;  // Increment hue for smooth transition
}

Da Temperatura a colore¶

CRGB temperatureColor(float temp) {
    // Map temperature (0-100°C) to hue (blue to red)
    uint8_t hue = map(temp, 0, 100, 160, 0);  // 160=blue, 0=red
    return CHSV(hue, 255, 255);
}

Effetto Desaturazione¶

void fadeToWhite() {
    static uint8_t saturation = 255;

    fill_solid(leds, NUM_LEDS, CHSV(96, saturation, 255));  // Green

    saturation--;  // Gradually desaturate to white
    if (saturation == 0) saturation = 255;  // Reset
}

Miscelazione dei Colori¶

Additivo (RGB)¶

CRGB color1 = CRGB(100, 0, 0);   // Dim red
CRGB color2 = CRGB(0, 100, 0);   // Dim green
CRGB result = color1 + color2;   // Yellow (200, 100, 0)

Miscelazione¶

CRGB color1 = CRGB::Red;
CRGB color2 = CRGB::Blue;

// Blend 50/50
CRGB result = blend(color1, color2, 128);  // Purple

// Blend 75% color2, 25% color1
CRGB result = blend(color1, color2, 192);

Best Practice¶

Utilizzare HSV per l’Animazione¶

// GOOD: Easy to animate
void rainbow() {
    static uint8_t hue = 0;
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = CHSV(hue + (i * 10), 255, 255);
    }
    hue++;
}

Utilizzare RGB per Colori Specifici¶

// GOOD: Direct control
leds[0] = CRGB(255, 64, 32);  // Specific amber color

Non Mescolare i Modelli Inutilmente¶

// AVOID: Converting back and forth
CHSV hsv = CHSV(128, 255, 255);
CRGB rgb = hsv;  // Convert to RGB
CHSV hsv2 = rgb;  // Can't convert back easily!

// BETTER: Stay in one model when possible
