Comprendere le Strutture Dati dei LED¶

Livello di Difficoltà: ⭐⭐ Da principiante a Intermedio Tempo di Completamento: 30-40 minuti Prerequisiti:

  • Concetti di Base - Comprensione dei principi fondamentali di FastLED

  • Primo Esempio - Esperienza di programmazione LED di base

Si imparerà:

  • Come lavorare con array CRGB e accedere ai singoli LED

  • Diversi modi per creare e manipolare i colori dei LED

  • Come eseguire operazioni di aritmetica e fusione dei colori

  • Considerazioni sulla memoria per array di LED su diverse piattaforme

  • Tecniche classiche di programmazione LED come il disegno dei pixel e i pattern di scansione

Come funzionano gli array di LED in FastLED.

L’Array CRGB¶

La struttura dati fondamentale in FastLED è l’array CRGB:

CRGB leds[NUM_LEDS];  // Array of RGB color values

Questo crea un array in cui ogni elemento rappresenta il colore di un LED.

Accesso ai singoli LED¶

Ogni LED ha un indice che parte da 0:

leds[0] = CRGB::Red;           // First LED
leds[5] = CRGB(255, 0, 128);   // Direct RGB values
leds[10].r = 200;              // Access red channel directly

Struttura CRGB¶

Un oggetto CRGB contiene tre canali colore:

CRGB color;
color.r = 255;  // Red channel (0-255)
color.g = 128;  // Green channel (0-255)
color.b = 64;   // Blue channel (0-255)

Creazione di Colori¶

Colori con Nome¶

leds[0] = CRGB::Red;
leds[1] = CRGB::Green;
leds[2] = CRGB::Blue;
leds[3] = CRGB::White;
leds[4] = CRGB::Black;  // Off

Valori RGB Diretti¶

leds[0] = CRGB(255, 0, 0);      // Red
leds[1] = CRGB(0, 255, 0);      // Green
leds[2] = CRGB(0, 0, 255);      // Blue
leds[3] = CRGB(255, 128, 64);   // Custom color

Colori HSV (Conversione Automatica)¶

leds[0] = CHSV(0, 255, 255);    // Red in HSV
leds[1] = CHSV(96, 255, 255);   // Green in HSV

Manipolazione dei Canali Colore¶

Accesso Diretto¶

CRGB color = CRGB::Purple;
color.r += 50;    // Increase red
color.g /= 2;     // Decrease green
color.b = 0;      // Remove blue

Operazioni sugli Array¶

// Set range of LEDs
for (int i = 0; i < 10; i++) {
    leds[i] = CRGB::Blue;
}

// Modify existing colors
for (int i = 0; i < NUM_LEDS; i++) {
    leds[i].r += 10;  // Add red to all LEDs
}

Aritmetica dei Colori¶

CRGB supporta le operazioni matematiche:

CRGB color1 = CRGB(100, 50, 25);
CRGB color2 = CRGB(50, 100, 25);

// Addition
CRGB result = color1 + color2;  // (150, 150, 50)

// Scaling
color1 *= 2;  // Double all channels (200, 100, 50)
color1 /= 2;  // Halve all channels (50, 25, 12)

// Modifying individual LEDs
leds[0] += CRGB(10, 0, 0);  // Add red

Considerazioni sulla Memoria¶

Ogni LED utilizza 3 byte di RAM:

Number of LEDs × 3 bytes = RAM used

Examples:
- 60 LEDs = 180 bytes
- 100 LEDs = 300 bytes
- 500 LEDs = 1500 bytes

Arduino Uno ha solo 2 KB di RAM in totale, il che limita la gestione di circa 300-400 LED (considerando il sovraccarico del programma).

Lavorare con i Range [Intervalli]¶

Riempire un Sottoinsieme¶

// Fill LEDs 10-19 with green
fill_solid(&leds[10], 10, CRGB::Green);

// Using pointer arithmetic
CRGB* startPos = &leds[20];
fill_solid(startPos, 15, CRGB::Blue);  // LEDs 20-34

Copiare Range¶

// Copy pattern from one section to another
for (int i = 0; i < 10; i++) {
    leds[i + 20] = leds[i];  // Copy LEDs 0-9 to 20-29
}

Best Practice¶

Utilizzare fill_solid per l’Efficienza¶

// GOOD: Use FastLED function
fill_solid(leds, NUM_LEDS, CRGB::Black);

// LESS EFFICIENT: Manual loop
for (int i = 0; i < NUM_LEDS; i++) {
    leds[i] = CRGB::Black;
}

Cancellare tutti i LED¶

// Option 1: fill_solid
fill_solid(leds, NUM_LEDS, CRGB::Black);

// Option 2: FastLED.clear (even faster)
FastLED.clear();  // Sets all to black, doesn't call show()

Controllare i Limiti dell’Array¶

int pos = calculatePosition();  // Some calculation

// Always validate before accessing
if (pos >= 0 && pos < NUM_LEDS) {
    leds[pos] = CRGB::Red;
}

Manipolazione dell’Array¶

Tecniche Classiche di Disegno LED¶

FastLED si basa sulle tecniche classiche di programmazione LED in cui è possibile manipolare direttamente array di pixel. Comprendere questi principi fondamentali è essenziale per creare qualsiasi effetto LED.

Indirizzamento Diretto dei Pixel¶

La forma più elementare di controllo LED: impostazione dei singoli pixel:

void drawPixel(int position, CRGB color) {
    if (position >= 0 && position < NUM_LEDS) {
        leds[position] = color;
    }
}

// Usage
drawPixel(10, CRGB::Red);
drawPixel(15, CRGB(0, 255, 128));

Disegno di Linee¶

Crea linee impostando LED consecutivi:

void drawLine(int start, int end, CRGB color) {
    if (start > end) {
        int temp = start;
        start = end;
        end = temp;
    }

    for (int i = start; i <= end && i < NUM_LEDS; i++) {
        leds[i] = color;
    }
}

// Draw a red line from LED 5 to LED 20
drawLine(5, 20, CRGB::Red);

Mappatura delle Coordinate XY per Matrici¶

Per le matrici LED 2D, converti le coordinate X e Y in indici di matrice:

#define MATRIX_WIDTH 16
#define MATRIX_HEIGHT 16

uint16_t XY(uint8_t x, uint8_t y) {
    if (x >= MATRIX_WIDTH || y >= MATRIX_HEIGHT) return 0;

    // Serpentine (zigzag) layout - most common wiring pattern
    if (y & 0x01) {
        // Odd rows run backwards
        return (y * MATRIX_WIDTH) + (MATRIX_WIDTH - 1 - x);
    } else {
        // Even rows run forwards
        return (y * MATRIX_WIDTH) + x;
    }
}

// Draw a pixel at X=5, Y=10
leds[XY(5, 10)] = CRGB::Blue;

// Draw a horizontal line
for (int x = 0; x < MATRIX_WIDTH; x++) {
    leds[XY(x, 8)] = CRGB::Green;
}

Blending e Layering¶

Combinare i colori anziché sostituirli:

// Additive blending (brightens)
leds[i] += CRGB(20, 20, 20);

// Averaging (mix colors)
CRGB color1 = leds[i];
CRGB color2 = CRGB::Blue;
leds[i] = blend(color1, color2, 128);  // 50% blend

Pattern classico: Scansione/Scanner Larson¶

Il classico effetto “Occhio del ciclone” o effetto “KITT”:

void larsonScanner() {
    static int pos = 0;
    static int direction = 1;

    // Fade all LEDs
    fadeToBlackBy(leds, NUM_LEDS, 20);

    // Draw the scanner
    leds[pos] = CRGB::Red;

    // Move position
    pos += direction;
    if (pos >= NUM_LEDS - 1 || pos <= 0) {
        direction = -direction;
    }
}

Queste tecniche classiche costituiscono la base di tutta la programmazione LED, dalle semplici strisce alle complesse installazioni 2D e 3D. Vedere Operazioni Matriciali/2D per tecniche di mappatura spaziale più avanzate.
