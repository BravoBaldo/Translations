Palette di Colori¶

Livello di Difficoltà: ⭐⭐ Intermedio Tempo di Completamento: 40-50 minuti Prerequisiti:

  • Pattern di Base - Comprensione delle funzioni di riempimento e delle animazioni

  • Teoria del Colore - Modelli di colore RGB e HSV

  • Animazioni - Variabili statiche e tempi

Si imparerà:

  • Come utilizzare le palette colori native di FastLED per creare combinazioni di colori professionali istantanee

  • Come creare palette personalizzate con definizioni di gradiente e specifiche di colore dirette

  • Come recuperare e miscelare i colori dalle palette utilizzando ColorFromPalette()

  • Tecniche di animazione delle palette: spostamento, allungamento, pulsazione e transizione tra palette

  • Tecniche avanzate che combinano palette con rumore, palette multiple e miscelazione uniforme delle palette con nblendPaletteTowardPalette()

Le palette di colori consentono di definire un set di colori e di miscelarli uniformemente. Questa è una delle funzionalità più potenti di FastLED per creare effetti cromatici sofisticati.

Perché Utilizzare le Palette?¶

  • Transizioni fluide: Fusione automatica dei colori

  • Facile da modificare: Scambio di interi schemi di colori modificando una sola riga

  • Aspetto professionale: Creazione di schemi di colori coesi

  • Memoria efficiente: Memorizzazione di gradienti complessi in modo compatto

Palette Predefinite¶

FastLED include diverse palette di colori native pronte all’uso:

#include <FastLED.h>

CRGBPalette16 palette = RainbowColors_p;  // Built-in rainbow palette

// Other built-in palettes:
// - PartyColors_p
// - CloudColors_p
// - LavaColors_p
// - OceanColors_p
// - ForestColors_p
// - HeatColors_p

Descrizioni delle Palette Native¶

  • RainbowColors_p: Arcobaleno a spettro completo

  • RainbowStripeColors_p: Arcobaleno con strisce nere

  • PartyColors_p: Colori vivaci per le feste (viola, arancione, blu)

  • CloudColors_p: Blu e bianco tenui per effetti nuvola

  • LavaColors_p: Rosso, arancione e giallo per effetti fuoco

  • OceanColors_p: Blu e acqua per effetti acqua

  • ForestColors_p: Toni verdi per effetti natura

  • HeatColors_p: Da nero a rosso a giallo a bianco (mappa termica)

Palette Personalizzate¶

Creare le palette di colori in base alle proprie esigenze specifiche:

// Define colors at specific positions (0-255)
DEFINE_GRADIENT_PALETTE(sunset_gp) {
    0,   255, 0,   0,    // Red at position 0
    128, 255, 128, 0,    // Orange at position 128
    255, 255, 255, 0     // Yellow at position 255
};

CRGBPalette16 sunsetPalette = sunset_gp;

Palette Personalizzata con Più Colori¶

DEFINE_GRADIENT_PALETTE(ocean_gp) {
    0,     0,   0,  128,   // Deep blue at start
    64,    0,  64,  255,   // Medium blue
    128,   0, 128,  255,   // Cyan
    192,   0, 255,  192,   // Light cyan
    255,  64, 255,  255    // White foam at end
};

CRGBPalette16 oceanPalette = ocean_gp;

Utilizzo delle Palette¶

a funzione ColorFromPalette() recupera i colori da una palette con “blending” [fusione] automatica:

void paletteEffect() {
    static uint8_t paletteIndex = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        // Calculate color index for this LED
        uint8_t colorIndex = paletteIndex + (i * 4);

        // Get color from palette with linear blending
        leds[i] = ColorFromPalette(palette, colorIndex, 255, LINEARBLEND);
    }

    paletteIndex++;  // Animate through palette
}

Parametri ColorFromPalette¶

ColorFromPalette(
    palette,      // The palette to use
    index,        // Color index (0-255)
    brightness,   // Brightness (0-255)
    blendType     // LINEARBLEND or NOBLEND
);

  • palette: Oggetto CRGBPalette16

  • index: Posizione nella palette (0-255, si riavvolge)

  • brightness: Moltiplicatore di luminosità generale

  • blendType:

    • LINEARBLEND: fumature uniformi (consigliato)

    • NOBLEND: Passaggi di colore discreti

Tecniche di Animazione della Palette¶

Spostamento nella Palette¶

void movingPalette() {
    static uint8_t startIndex = 0;

    startIndex++;  // Move through palette over time

    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t colorIndex = startIndex + (i * 2);
        leds[i] = ColorFromPalette(palette, colorIndex, 255, LINEARBLEND);
    }
}

Allargamento della Palette¶

void stretchedPalette() {
    for (int i = 0; i < NUM_LEDS; i++) {
        // Map LED position to full palette range
        uint8_t colorIndex = map(i, 0, NUM_LEDS-1, 0, 255);
        leds[i] = ColorFromPalette(palette, colorIndex, 255, LINEARBLEND);
    }
}

Luminosità Dinamica¶

void palettePulse() {
    static uint8_t paletteIndex = 0;
    uint8_t brightness = beatsin8(15, 50, 255);  // Pulsing brightness

    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t colorIndex = paletteIndex + (i * 3);
        leds[i] = ColorFromPalette(palette, colorIndex, brightness, LINEARBLEND);
    }

    paletteIndex++;
}

Fusione della Palette¶

Transizione fluida tra diverse palette:

CRGBPalette16 currentPalette;
CRGBPalette16 targetPalette;

void setup() {
    currentPalette = RainbowColors_p;
    targetPalette = LavaColors_p;
}

void loop() {
    // Blend toward target palette
    EVERY_N_MILLISECONDS(10) {
        nblendPaletteTowardPalette(currentPalette, targetPalette, 12);
    }

    // Change target palette periodically
    EVERY_N_SECONDS(5) {
        targetPalette = targetPalette == RainbowColors_p ?
                        LavaColors_p : RainbowColors_p;
    }

    // Use current palette
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = ColorFromPalette(currentPalette, i * 4, 255, LINEARBLEND);
    }

    FastLED.show();
}

Tecniche Avanzate per la Palette¶

Selezione della Palette Basata sul Rumore¶

void noisyPalette() {
    for (int i = 0; i < NUM_LEDS; i++) {
        // Use noise to select palette color
        uint8_t noise = inoise8(i * 50, millis() / 10);
        leds[i] = ColorFromPalette(palette, noise, 255, LINEARBLEND);
    }
}

Palette Multiple¶

CRGBPalette16 palette1 = RainbowColors_p;
CRGBPalette16 palette2 = LavaColors_p;

void dualPalette() {
    for (int i = 0; i < NUM_LEDS; i++) {
        // Alternate between palettes
        CRGBPalette16 &usePalette = (i % 2) ? palette1 : palette2;
        leds[i] = ColorFromPalette(usePalette, i * 8, 255, LINEARBLEND);
    }
}

Palette Migliore Pratiche¶

  1. Usare LINEARBLEND: Usare quasi sempre LINEARBLEND per effetti più fluidi

  2. Spaziatura indice: Moltiplicare l’indice LED per 2-8 per una buona distribuzione del colore

  3. Velocità di animazione: Aumentare l’indice di 1-4 per fotogramma per un movimento fluido

  4. Luminosità: Usare la luminosità massima (255) a meno che non si desideri una pulsazione

  5. Transizioni di palette: Usare nblendPaletteTowardPalette() per modifiche fluide

Esempio: Effetto Palette Completo¶

#include <FastLED.h>

#define NUM_LEDS 60
#define DATA_PIN 6

CRGB leds[NUM_LEDS];
CRGBPalette16 currentPalette;
CRGBPalette16 targetPalette;
TBlendType currentBlending = LINEARBLEND;

void setup() {
    FastLED.addLeds<WS2812B, DATA_PIN, GRB>(leds, NUM_LEDS);
    FastLED.setBrightness(50);

    currentPalette = RainbowColors_p;
    targetPalette = RainbowColors_p;
}

void loop() {
    // Change palette every 5 seconds
    EVERY_N_SECONDS(5) {
        ChangePalettePeriodically();
    }

    // Blend toward target palette
    EVERY_N_MILLISECONDS(10) {
        nblendPaletteTowardPalette(currentPalette, targetPalette, 12);
    }

    // Animate palette
    static uint8_t startIndex = 0;
    startIndex++;

    FillLEDsFromPaletteColors(startIndex);

    FastLED.show();
    FastLED.delay(1000 / 60);  // 60 FPS
}

void FillLEDsFromPaletteColors(uint8_t colorIndex) {
    uint8_t brightness = 255;

    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = ColorFromPalette(currentPalette, colorIndex, brightness, currentBlending);
        colorIndex += 3;
    }
}

void ChangePalettePeriodically() {
    uint8_t secondHand = (millis() / 1000) % 60;
    static uint8_t lastSecond = 99;

    if (lastSecond != secondHand) {
        lastSecond = secondHand;
        if (secondHand == 0) { targetPalette = RainbowColors_p; }
        if (secondHand == 10) { targetPalette = LavaColors_p; }
        if (secondHand == 20) { targetPalette = OceanColors_p; }
        if (secondHand == 30) { targetPalette = ForestColors_p; }
        if (secondHand == 40) { targetPalette = PartyColors_p; }
        if (secondHand == 50) { targetPalette = CloudColors_p; }
    }
}
