Rumore e Rumore di Perlin¶

Livello di Difficoltà: ⭐⭐ Intermedio Tempo di Completamento: 45-55 minuti Prerequisiti:

  • Palette di Colori - Il rumore viene spesso combinato con le palette per effetti sorprendenti

  • Teoria del Colore - Comprensione dei modelli di colore HSV e RGB

  • Animazioni - Comprensione delle variabili statiche e dei tempi

Si imparerà:

  • Cos’è il rumore di Perlin e in cosa si differenzia dai valori casuali per creare animazioni fluide e organiche

  • Utilizzo delle funzioni di rumore di FastLED (inoise8, inoise16) in 1D, 2D e 3D per effetti di diversa complessità

  • Controllo dei parametri di rumore: coordinate spaziali (fluidità), componente temporale (velocità di animazione) e dimensione Z (profondità)

  • Combinazione di rumore con palette di colori per creare effetti naturali come lampade lava, nuvole, onde dell’oceano e fuoco

  • Tecniche avanzate: rumore a strati per pattern più ricchi, luminosità controllata dal rumore e movimento basato sul rumore

FastLED include funzioni di rumore per creare animazioni organiche e dall’aspetto naturale. A differenza dei valori casuali, il rumore produce pattern fluidi e continui che scorrono naturalmente nel tempo e nello spazio.

Cos’è il Rumore di Perlin?¶

Il rumore di Perlin è un tipo di rumore gradiente che crea una casualità fluida e dall’aspetto naturale. Viene comunemente utilizzato per:

  • Effetti lampada lava

  • Movimento delle nuvole

  • Movimento del fuoco

  • Pattern fluidi organici

  • Generazione di terreni

A differenza di random() che produce cambiamenti bruschi, il rumore crea transizioni fluide tra i valori.

Funzioni di Base del Rumore¶

FastLED fornisce diverse funzioni di rumore:

// 1D noise (single parameter)
uint8_t inoise8(uint16_t x);

// 2D noise (two parameters)
uint8_t inoise8(uint16_t x, uint16_t y);

// 3D noise (three parameters)
uint8_t inoise8(uint16_t x, uint16_t y, uint16_t z);

// 16-bit noise for higher precision
uint16_t inoise16(uint32_t x, uint32_t y, uint32_t z);

Tutte le funzioni di rumore restituiscono valori compresi tra 0 e 255 (per inoise8) o 0-65535 (per inoise16).

Esempio di Rumore di Base¶

void noiseEffect() {
    static uint16_t x = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        // Generate noise value (0-255)
        uint8_t noise = inoise8(x + (i * 100), millis() / 10);

        // Map to color (hue)
        leds[i] = CHSV(noise, 255, 255);
    }

    x += 10;  // Move through noise space
}

Comprendere i Parametri del Rumore¶

La chiave per usare il rumore in modo efficace è capire come i parametri influenzano l’output:

Coordinate Spaziali¶

// Each LED gets a different position in noise space
for (int i = 0; i < NUM_LEDS; i++) {
    uint8_t noise = inoise8(i * 50);  // Spacing controls smoothness
    leds[i] = CHSV(noise, 255, 255);
}

  • Spaziatura piccola (10-50): Transizioni molto fluide

  • Spaziatura media (50-100): Aspetto bilanciato e naturale

  • Spaziatura grande (100-300): Modifiche più caotiche e rapide

Componente Tempo¶

void animatedNoise() {
    for (int i = 0; i < NUM_LEDS; i++) {
        // Add time-based animation
        uint8_t noise = inoise8(
            i * 50,            // Spatial position
            millis() / 20      // Time component
        );
        leds[i] = CHSV(noise, 255, 255);
    }
}

Il divisore di millis() controlla la velocità dell’animazione:

  • /100: Movimento lento e delicato

  • /50: Velocità moderata

  • /20: Movimento veloce

  • /10: Molto veloce

Rumore 2D per il Movimento¶

L’utilizzo di due dimensioni crea pattern più complessi e organici:

void lavaLamp() {
    for (int i = 0; i < NUM_LEDS; i++) {
        // Create time-varying noise
        uint8_t noise = inoise8(
            i * 50,                    // X position (spatial)
            millis() / 20 + i * 10     // Y position (time-based)
        );

        // Use with heat colors palette
        leds[i] = ColorFromPalette(HeatColors_p, noise);
    }
}

Rumore 3D¶

Tre dimensioni forniscono i pattern più complessi e interessanti:

void complexNoise() {
    static uint16_t z = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t noise = inoise8(
            i * 50,           // X: spatial position
            millis() / 20,    // Y: time
            z                 // Z: additional animation dimension
        );

        leds[i] = CHSV(noise, 255, 255);
    }

    z += 1;  // Slowly move through Z dimension
}

Rumore con Palette di Colori¶

Combinare il rumore con le palette crea effetti bellissimi:

void noisePalette() {
    CRGBPalette16 palette = OceanColors_p;

    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t noise = inoise8(i * 60, millis() / 30);
        leds[i] = ColorFromPalette(palette, noise, 255, LINEARBLEND);
    }
}

Rumore a Strati¶

Combinare più layer di rumore per effetti più ricchi:

void layeredNoise() {
    for (int i = 0; i < NUM_LEDS; i++) {
        // Two noise layers with different scales
        uint8_t noise1 = inoise8(i * 30, millis() / 20);
        uint8_t noise2 = inoise8(i * 80, millis() / 50);

        // Combine layers
        uint8_t combined = (noise1 + noise2) / 2;

        leds[i] = CHSV(combined, 255, 255);
    }
}

Onde dell’Oceano¶

void oceanWaves() {
    CRGBPalette16 oceanPalette = OceanColors_p;
    static uint16_t z = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        // Three layers for depth
        uint8_t noise1 = inoise8(i * 40, millis() / 30, z);
        uint8_t noise2 = inoise8(i * 70, millis() / 40, z + 1000);
        uint8_t combined = (noise1 + noise2) / 2;

        leds[i] = ColorFromPalette(oceanPalette, combined, 255, LINEARBLEND);
    }

    z += 2;
}

Rumore Arcobaleno¶

void rainbowNoise() {
    static uint16_t offset = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t noise = inoise8(i * 50 + offset, millis() / 20);
        leds[i] = CHSV(noise, 200, 255);
    }

    offset += 5;
}

Rumore con Luminosità¶

Usare il rumore per controllare la luminosità anziché il colore:

void noiseBrightness() {
    CRGB baseColor = CRGB::Blue;

    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t brightness = inoise8(i * 60, millis() / 30);

        leds[i] = baseColor;
        leds[i].nscale8(brightness);
    }
}

Considerazioni sulle Prestazioni¶

Le funzioni di rumore sono computazionalmente efficienti, ma ecco alcuni suggerimenti:

  1. Riutilizzare i valori: Se più LED utilizzano lo stesso rumore, calcolare una volta

  2. Regolare la spaziatura: Incrementi maggiori = meno fluidi ma più veloci

  3. Limitare le dimensioni: Il rumore 2D è più veloce del 3D

  4. Considerare il frame rate: Obiettivo 30-60 FPS per un’animazione fluida

Guida ai Parametri del Rumore¶

Parametro X (spaziale)¶

  • Controlla la posizione lungo la striscia

  • Moltiplica l’indice LED per 20-100

  • Più grande = maggiore variazione tra LED adiacenti

Parametro Y (Tempo)¶

  • Di solito millis() / divisore

  • Il divisore 10-100 controlla la velocità

  • Un divisore più piccolo = animazione più veloce

Parametro Z (Dimensione extra)¶

  • Aggiunge un ulteriore layer di animazione

  • Incremento lento (1-5 per fotogramma)

  • Crea “profondità” all’animazione

Problemi Comuni¶

Troppo Caotico¶

// Problem: Too much variation
uint8_t noise = inoise8(i * 200, millis() / 5);

// Solution: Reduce spacing and slow down
uint8_t noise = inoise8(i * 50, millis() / 30);

Troppo Statico¶

// Problem: Barely moving
uint8_t noise = inoise8(i * 10, millis() / 200);

// Solution: Increase spacing or speed up
uint8_t noise = inoise8(i * 50, millis() / 30);

Troppo Uniforme¶

// Problem: All LEDs same color
uint8_t noise = inoise8(i, millis() / 30);

// Solution: Increase spatial multiplier
uint8_t noise = inoise8(i * 50, millis() / 30);

Avanzato: Movimento Basato sul Rumore¶

Creare pattern in movimento usando il rumore per controllare la posizione:

void noisyMovement() {
    fadeToBlackBy(leds, NUM_LEDS, 50);

    // Use noise to determine which LED to light
    uint8_t pos = inoise8(millis() / 10) % NUM_LEDS;
    leds[pos] = CHSV(160, 255, 255);
}

Esempio Completo¶

#include <FastLED.h>

#define NUM_LEDS 60
#define DATA_PIN 6

CRGB leds[NUM_LEDS];
CRGBPalette16 currentPalette = OceanColors_p;

void setup() {
    FastLED.addLeds<WS2812B, DATA_PIN, GRB>(leds, NUM_LEDS);
    FastLED.setBrightness(100);
}

void loop() {
    noiseEffect();
    FastLED.show();
    FastLED.delay(1000 / 60);  // 60 FPS
}

void noiseEffect() {
    static uint16_t z = 0;

    for (int i = 0; i < NUM_LEDS; i++) {
        // Generate smooth noise
        uint8_t noise = inoise8(
            i * 50,           // Spatial spacing
            millis() / 30,    // Time-based animation
            z                 // Extra dimension
        );

        // Map to palette
        leds[i] = ColorFromPalette(currentPalette, noise, 255, LINEARBLEND);
    }

    z += 2;  // Move through Z dimension
}
