Fusione e Transizioni¶

Livello di Difficoltà: ⭐⭐ Intermedio Tempo di Completamento: 40-50 minuti Prerequisiti:

  • Pattern di base - Animazioni - Comprensione delle variabili statiche e della tempistica

  • Teoria del Colore - Modelli di colore RGB e HSV

  • Controllo del Tempo e dell’Animazione - oncetti di frame rate e temporizzazione

Si imparerà:

  • Come sfumare in modo fluido i colori usando blend() e controllare l’interpolazione con le quantità di sfumatura

  • Creare effetti di dissolvenza con fadeToBlackBy() e sfumare a colori specifici per scie e transizioni

  • Utilizzare blur1d() per creare gradienti uniformi e ammorbidire i bordi netti

  • Dissolvenza incrociata tra pattern completi e sovrapposizione di più effetti

  • Tecniche di sfumatura avanzate: sfumatura additiva/sottrattiva, ridimensionamento della luminosità e funzioni di attenuazione per un movimento naturale

La sfumatura e le transizioni sono tecniche essenziali per creare animazioni LED fluide e dall’aspetto professionale. FastLED offre potenti funzioni per dissolvenza, fusione e transizione tra colori e pattern.

Perché la Fusione è Importante¶

  • Aspetto professionale: Le transizioni fluide appaiono più pulite

  • Movimento naturale: Imita il comportamento della luce nel mondo reale

  • Continuità del pattern: Crea effetti fluidi senza cambiamenti bruschi

  • Controllo creativo: Ottimizza l’aspetto delle animazioni

Fusione dei Colori¶

Fusione dei Colori di Base¶

La funzione blend() interpola in modo fluido tra due colori:

void smoothTransition() {
    static uint8_t blendAmount = 0;
    CRGB color1 = CRGB::Red;
    CRGB color2 = CRGB::Blue;

    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = blend(color1, color2, blendAmount);
    }

    blendAmount++;  // 0-255, controls mix
}

Parametri Blend:

  • color1: Colore iniziale

  • color2: Colore finale

  • amount: 0 = tutto il colore 1, 255 = tutto il colore 2, 128 = miscela 50/50

Blending Spaziale¶

Creare gradienti variando la quantità di fusione sui LED:

void gradientBlend() {
    CRGB color1 = CRGB::Purple;
    CRGB color2 = CRGB::Cyan;

    for (int i = 0; i < NUM_LEDS; i++) {
        // Calculate blend amount for this LED
        uint8_t blendAmount = map(i, 0, NUM_LEDS-1, 0, 255);
        leds[i] = blend(color1, color2, blendAmount);
    }
}

Fusione di più Colori¶

void triColorBlend() {
    CRGB color1 = CRGB::Red;
    CRGB color2 = CRGB::Green;
    CRGB color3 = CRGB::Blue;

    for (int i = 0; i < NUM_LEDS; i++) {
        if (i < NUM_LEDS / 2) {
            // Blend from color1 to color2 (first half)
            uint8_t amount = map(i, 0, NUM_LEDS/2, 0, 255);
            leds[i] = blend(color1, color2, amount);
        } else {
            // Blend from color2 to color3 (second half)
            uint8_t amount = map(i, NUM_LEDS/2, NUM_LEDS-1, 0, 255);
            leds[i] = blend(color2, color3, amount);
        }
    }
}

Dissolvenza in Nero¶

Dissolvenza in Nero di Base¶

Crea effetti di scie e decadimento:

void trailEffect() {
    // Fade all LEDs toward black
    fadeToBlackBy(leds, NUM_LEDS, 20);  // 20 = fade speed (0-255)

    // Add new LED
    static uint8_t pos = 0;
    leds[pos] = CRGB::White;
    pos = (pos + 1) % NUM_LEDS;
}

Guida alla Velocità di Dissolvenza:

  • 5-10: Dissolvenza molto lenta, scie lunghe

  • 20-40: Dissolvenza moderata, buona per la maggior parte degli effetti

  • 50-100: Dissolvenza rapida, scie brevi

  • 150-255: Dissolvenza molto rapida, quasi istantanea

Velocità di Dissolvenza Variabili¶

Parti diverse possono dissolversi a velocità diverse:

void variableFade() {
    // Fade first half slowly
    fadeToBlackBy(leds, NUM_LEDS/2, 10);

    // Fade second half quickly
    fadeToBlackBy(&leds[NUM_LEDS/2], NUM_LEDS/2, 50);
}

Dissolvenza a un Colore Specifico¶

void fadeToColor(CRGB targetColor, uint8_t fadeAmount) {
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = blend(leds[i], targetColor, fadeAmount);
    }
}

void loop() {
    // Gradually fade to blue
    fadeToColor(CRGB::Blue, 10);
    FastLED.show();
    delay(20);
}

Effetti di Sfocatura¶

La sfocatura crea gradienti uniformi calcolando la media dei LED adiacenti:

void blurExample() {
    // Set some random LEDs
    leds[random8(NUM_LEDS)] = CHSV(random8(), 255, 255);

    // Blur to create smooth gradients
    blur1d(leds, NUM_LEDS, 50);  // 50 = blur amount
}

Guida all’Intensità della Sfocatura:

  • 10-30: Sfocatura leggera

  • 50-100: Sfocatura moderata, buona per la maggior parte degli effetti

  • 150-200: Sfocatura intensa, molto uniforme

  • 255: Sfocatura massima

Sfocatura per l’Uniformità¶

void smoothMovement() {
    // Create sharp point
    static uint8_t pos = 0;
    leds[pos] = CRGB::Red;

    // Blur to smooth it out
    blur1d(leds, NUM_LEDS, 100);

    // Fade everything slightly
    fadeToBlackBy(leds, NUM_LEDS, 10);

    pos = (pos + 1) % NUM_LEDS;
}

Dissolvenza Incrociata di Pattern¶

Transizione uniforme tra due pattern completi:

CRGB pattern1[NUM_LEDS];
CRGB pattern2[NUM_LEDS];

void crossFade(uint8_t amount) {
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = blend(pattern1[i], pattern2[i], amount);
    }
}

void loop() {
    static uint8_t crossFadeAmount = 0;

    // Prepare pattern 1 (rainbow)
    fill_rainbow(pattern1, NUM_LEDS, 0, 5);

    // Prepare pattern 2 (solid color)
    fill_solid(pattern2, NUM_LEDS, CRGB::Purple);

    // Cross-fade between them
    crossFade(crossFadeAmount);

    EVERY_N_MILLISECONDS(20) {
        if (crossFadeAmount < 255) {
            crossFadeAmount += 5;
        }
    }

    FastLED.show();
}

Tecniche di Fusione Avanzate¶

Fusione Additiva¶

Sommare i colori (ottimo per gli effetti di luce):

void additiveBlend() {
    CRGB layer1 = CRGB(100, 0, 0);     // Dim red
    CRGB layer2 = CRGB(0, 100, 0);     // Dim green

    leds[0] = layer1 + layer2;         // Results in yellow (100, 100, 0)
}

Fusione Sottrattiva¶

Sottrazione di Colori (attenzione all’underflow):

void subtractiveBlend() {
    leds[0] = CRGB(200, 100, 50);
    leds[0] -= CRGB(50, 50, 50);       // Results in (150, 50, 0)
}

Luminosità Scalata¶

void scaleBrightness() {
    leds[0] = CRGB::Red;
    leds[0].nscale8(128);              // Scale to 50% brightness
}

Ridimensionamento per Canale¶

void colorTemperature() {
    CRGB color = CRGB::White;

    // Warm white: reduce blue
    color.b = scale8(color.b, 128);
    leds[0] = color;
}

Tempi di Transizione¶

Transizioni Lineari¶

void linearTransition() {
    static uint8_t progress = 0;
    CRGB startColor = CRGB::Blue;
    CRGB endColor = CRGB::Red;

    fill_solid(leds, NUM_LEDS, blend(startColor, endColor, progress));

    progress += 2;  // Linear progression
}

Transizioni Fluide¶

Aggiungi un effetto di fluidità per un movimento più naturale:

uint8_t easeInOutCubic(uint8_t t) {
    if (t < 128) {
        return ((uint16_t)t * t * t) >> 14;
    } else {
        uint16_t t2 = 255 - t;
        return 255 - (((t2 * t2 * t2) >> 14));
    }
}

void easedTransition() {
    static uint8_t time = 0;
    uint8_t easedTime = easeInOutCubic(time);

    CRGB color1 = CRGB::Green;
    CRGB color2 = CRGB::Purple;

    fill_solid(leds, NUM_LEDS, blend(color1, color2, easedTime));

    time += 2;
}

Transizioni Basate su Onde¶

void waveTransition() {
    // Use sine wave for smooth back-and-forth
    uint8_t wave = beatsin8(10, 0, 255);  // 10 BPM

    CRGB color1 = CRGB::Cyan;
    CRGB color2 = CRGB::Magenta;

    fill_solid(leds, NUM_LEDS, blend(color1, color2, wave));
}

Effetti a Strati¶

void layeredEffect() {
    // Layer 1: Slow moving wave
    static uint8_t wave1 = 0;
    for (int i = 0; i < NUM_LEDS; i++) {
        uint8_t brightness = sin8(wave1 + (i * 10));
        leds[i] = CHSV(160, 255, brightness / 2);
    }
    wave1 += 2;

    // Layer 2: Fast twinkles (additive)
    if (random8() < 30) {
        int pos = random16(NUM_LEDS);
        leds[pos] += CRGB(50, 50, 50);
    }
}

Migliori Pratiche per la Fusione¶

  1. Iniziare con delicatezza: Piccole quantità di dissolvenza (5-20) spesso danno risultati migliori

  2. Usare la sfocatura con parsimonia: Troppa sfocatura può dare un effetto poco nitido

  3. Combinare le tecniche: Dissolvenza + sfocatura creano effetti fluidi e fluidi

  4. Verificare i tempi: Regolare la velocità fino a ottenere un movimento naturale

  5. Considerare la potenza: La dissolvenza riduce la luminosità e il consumo energetico

Suggerimenti per le Prestazioni¶

// Efficient: Fade entire array at once
fadeToBlackBy(leds, NUM_LEDS, 20);

// Inefficient: Fade each LED individually
for (int i = 0; i < NUM_LEDS; i++) {
    leds[i].fadeToBlackBy(20);
}

Errori Comuni¶

Dissolvenza Troppo Rapida¶

// Problem: Disappears too quickly
fadeToBlackBy(leds, NUM_LEDS, 200);

// Better: Slower fade
fadeToBlackBy(leds, NUM_LEDS, 30);

Superamento della Quantità di Fusione¶

// Problem: Can wrap around
uint8_t amount = 250;
amount += 10;  // Wraps to 4!

// Better: Use constrain or check
amount = min(amount + 10, 255);

Dimenticare di Mostrare¶

// Problem: Changes not visible
fadeToBlackBy(leds, NUM_LEDS, 20);
// Missing: FastLED.show();

// Correct:
fadeToBlackBy(leds, NUM_LEDS, 20);
FastLED.show();

Esempio Completo¶

#include <FastLED.h>

#define NUM_LEDS 60
#define DATA_PIN 6

CRGB leds[NUM_LEDS];

void setup() {
    FastLED.addLeds<WS2812B, DATA_PIN, GRB>(leds, NUM_LEDS);
    FastLED.setBrightness(100);
}

void loop() {
    blendedChase();
    FastLED.show();
    FastLED.delay(1000 / 60);
}

void blendedChase() {
    static uint8_t pos = 0;
    static uint8_t hue = 0;

    // Fade all LEDs gradually
    fadeToBlackBy(leds, NUM_LEDS, 30);

    // Add bright LED at current position
    leds[pos] = CHSV(hue, 255, 255);

    // Blur to create smooth trail
    blur1d(leds, NUM_LEDS, 80);

    // Move to next position
    EVERY_N_MILLISECONDS(50) {
        pos = (pos + 1) % NUM_LEDS;
        hue += 4;
    }
}
