Coordinazione a più Strisce¶

Livello di Difficoltà: ⭐⭐⭐ Avanzato Tempo di Completamento: 40-50 minuti Prerequisiti:

  • Guida Introduttiva - Controllo LED di base e configurazione FastLED

  • Concetti Fondamentali - In particolare array e temporizzazione

  • Pattern di Base - Programmazione di pattern e animazioni

  • Tecniche Intermedie - Utilità matematiche e pattern di coordinamento

Si imparerà:

  1. Come controllare più strisce LED da un singolo microcontrollore

  2. Tecniche per sincronizzare gli effetti su più strisce

  3. Come creare effetti wave e “chase” [sequenze] che si estendono su più strisce

  5. Considerazioni sulle prestazioni, utilizzo della memoria e risoluzione dei problemi per configurazioni multi-striscia

Controllare più strisce LED in modo indipendente o coordinato per installazioni più grandi ed effetti complessi.

Configurazione di più Controller¶

FastLED semplifica il controllo di più strisce LED da un singolo microcontrollore.

#define NUM_STRIPS 3
#define LEDS_PER_STRIP 60

CRGB strip1[LEDS_PER_STRIP];
CRGB strip2[LEDS_PER_STRIP];
CRGB strip3[LEDS_PER_STRIP];

void setup() {
    FastLED.addLeds<WS2812B, 5, GRB>(strip1, LEDS_PER_STRIP);
    FastLED.addLeds<WS2812B, 6, GRB>(strip2, LEDS_PER_STRIP);
    FastLED.addLeds<WS2812B, 7, GRB>(strip3, LEDS_PER_STRIP);
}

Array di più Strisce¶

È anche possibile utilizzare un array di array per una gestione più semplice:

#define NUM_STRIPS 4
#define LEDS_PER_STRIP 60

CRGB strips[NUM_STRIPS][LEDS_PER_STRIP];

void setup() {
    FastLED.addLeds<WS2812B, 5, GRB>(strips[0], LEDS_PER_STRIP);
    FastLED.addLeds<WS2812B, 6, GRB>(strips[1], LEDS_PER_STRIP);
    FastLED.addLeds<WS2812B, 7, GRB>(strips[2], LEDS_PER_STRIP);
    FastLED.addLeds<WS2812B, 8, GRB>(strips[3], LEDS_PER_STRIP);
}

Effetti Sincronizzati¶

Applicare lo stesso pattern a tutte le strisce contemporaneamente.

void syncedRainbow() {
    static uint8_t hue = 0;

    // Same pattern on all strips
    fill_rainbow(strip1, LEDS_PER_STRIP, hue, 5);
    fill_rainbow(strip2, LEDS_PER_STRIP, hue, 5);
    fill_rainbow(strip3, LEDS_PER_STRIP, hue, 5);

    hue++;
}

Utilizzo di Loop per la Sincronizzazione¶

void syncedPattern() {
    static uint8_t hue = 0;

    for (int s = 0; s < NUM_STRIPS; s++) {
        fill_rainbow(strips[s], LEDS_PER_STRIP, hue, 5);
    }

    hue++;
}

Controllo Indipendente¶

Ogni striscia esegue un effetto diverso.

void independentEffects() {
    // Strip 1: Rainbow
    static uint8_t hue1 = 0;
    fill_rainbow(strip1, LEDS_PER_STRIP, hue1, 5);
    hue1++;

    // Strip 2: Solid color breathing
    uint8_t brightness = beatsin8(30);
    fill_solid(strip2, LEDS_PER_STRIP, CHSV(160, 255, brightness));

    // Strip 3: Scanner/Cylon
    static uint8_t pos = 0;
    fadeToBlackBy(strip3, LEDS_PER_STRIP, 20);
    strip3[pos] = CRGB::Red;
    pos = (pos + 1) % LEDS_PER_STRIP;
}

Effetto Wave tra le Strisce¶

Creare effetti che si spostano da una striscia all’altra.

void waveAcrossStrips() {
    static uint8_t pos = 0;

    // Calculate position on virtual combined strip
    uint16_t totalLEDs = NUM_STRIPS * LEDS_PER_STRIP;
    uint16_t virtualPos = map(pos, 0, 255, 0, totalLEDs);

    // Clear all
    fill_solid(strip1, LEDS_PER_STRIP, CRGB::Black);
    fill_solid(strip2, LEDS_PER_STRIP, CRGB::Black);
    fill_solid(strip3, LEDS_PER_STRIP, CRGB::Black);

    // Determine which strip and position
    if (virtualPos < LEDS_PER_STRIP) {
        strip1[virtualPos] = CRGB::White;
    } else if (virtualPos < LEDS_PER_STRIP * 2) {
        strip2[virtualPos - LEDS_PER_STRIP] = CRGB::White;
    } else {
        strip3[virtualPos - LEDS_PER_STRIP * 2] = CRGB::White;
    }

    pos++;
}

Funzione d’Onda Generalizzata¶

void generalizedWave() {
    static uint8_t phase = 0;

    for (int s = 0; s < NUM_STRIPS; s++) {
        // Create wave with phase offset per strip
        for (int i = 0; i < LEDS_PER_STRIP; i++) {
            uint8_t brightness = sin8(phase + (s * 40) + (i * 5));
            strips[s][i] = CHSV(160, 255, brightness);
        }
    }

    phase += 2;
}

Pattern Coordinati¶

Strisce Alternate¶

void alternatingStrips() {
    static uint8_t state = 0;
    EVERY_N_MILLISECONDS(500) {
        state = !state;
    }

    if (state) {
        fill_solid(strip1, LEDS_PER_STRIP, CRGB::Red);
        fill_solid(strip2, LEDS_PER_STRIP, CRGB::Black);
        fill_solid(strip3, LEDS_PER_STRIP, CRGB::Red);
    } else {
        fill_solid(strip1, LEDS_PER_STRIP, CRGB::Black);
        fill_solid(strip2, LEDS_PER_STRIP, CRGB::Blue);
        fill_solid(strip3, LEDS_PER_STRIP, CRGB::Black);
    }
}

Chase tra Strisce¶

void chaseAcrossStrips() {
    static uint8_t stripIndex = 0;
    static uint8_t ledIndex = 0;

    // Fade all
    fadeToBlackBy(strip1, LEDS_PER_STRIP, 50);
    fadeToBlackBy(strip2, LEDS_PER_STRIP, 50);
    fadeToBlackBy(strip3, LEDS_PER_STRIP, 50);

    // Light current position
    switch(stripIndex) {
        case 0: strip1[ledIndex] = CRGB::White; break;
        case 1: strip2[ledIndex] = CRGB::White; break;
        case 2: strip3[ledIndex] = CRGB::White; break;
    }

    // Advance position
    ledIndex++;
    if (ledIndex >= LEDS_PER_STRIP) {
        ledIndex = 0;
        stripIndex = (stripIndex + 1) % NUM_STRIPS;
    }
}

Strisce Combinate Virtuali¶

Trattare più strisce come un’unica striscia continua.

// Helper function to set LED on virtual strip
void setVirtualLED(uint16_t index, CRGB color) {
    uint8_t stripNum = index / LEDS_PER_STRIP;
    uint8_t ledNum = index % LEDS_PER_STRIP;

    if (stripNum < NUM_STRIPS) {
        strips[stripNum][ledNum] = color;
    }
}

void virtualStripEffect() {
    uint16_t totalLEDs = NUM_STRIPS * LEDS_PER_STRIP;

    // Treat as single rainbow
    for (uint16_t i = 0; i < totalLEDs; i++) {
        uint8_t hue = map(i, 0, totalLEDs, 0, 255);
        setVirtualLED(i, CHSV(hue, 255, 255));
    }
}

Considerazioni sulle Prestazioni¶

Aggiornare Tutte le Strisce Insieme¶

void loop() {
    updateAllStrips();
    FastLED.show();  // Updates all controllers at once
    delay(20);
}

FastLED.show() aggiorna tutti i controller registrati in modo efficiente, quindi non è necessario richiamarlo separatamente per ogni striscia.

Utilizzo della Memoria¶

Ogni LED utilizza 3 byte (RGB). Pianificare di conseguenza:

  • 3 strisce × 60 LED = 180 LED = 540 byte

  • 5 strisce × 100 LED = 500 LED = 1.500 byte

Assicurarsi che il microcontrollore abbia RAM sufficiente.

Selezione dei Pin¶

Scegliere i pin che supportano le funzionalità hardware della piattaforma:

  • ESP32: Usa pin compatibili con RMT per prestazioni ottimali

  • Arduino: Funziona qualsiasi pin digitale

  • Teensy: Qualsiasi pin, ottima uscita parallela

  • ESP8266: Pin limitati, usa GPIO con cautela

Risoluzione dei problemi¶

Una striscia non funziona:

  • Verificare l’assegnazione dei pin in addLeds()

  • Verificare i collegamenti di alimentazione di quella striscia

  • Testare la striscia in modo indipendente

  • Verificare che l’ordine dei colori corrisponda al tipo di striscia

Le strisce sfarfallano a velocità diverse:

  • Assicurarsi che FastLED.show() venga chiamato una volta per frame

  • Verificare che tutte le strisce utilizzino lo stesso frame rate

  • Verifica la capacità dell’alimentatore

Problemi di memoria:

  • Calcolare la memoria LED totale: NUM_STRIPS × LEDS_PER_STRIP × 3 byte

  • Valutare la possibilità di ridurre il numero o la lunghezza delle strisce

  • Usare l’allocazione dinamica con cautela

Problemi di temporizzazione con molte strisce:

  • Alcune piattaforme possono aggiornare tutte le strisce in parallelo (ESP32, Teensy)

  • Altri si aggiornano serialmente (Arduino Uno)

  • Regolare il frame rate se gli aggiornamenti richiedono troppo tempo

Tecniche Avanzate¶

Gruppi di Strisce¶

Creare gruppi di strisce per una gestione più semplice:

void updateStripGroup(int startStrip, int endStrip, CRGB color) {
    for (int s = startStrip; s <= endStrip; s++) {
        fill_solid(strips[s], LEDS_PER_STRIP, color);
    }
}

void groupedEffect() {
    updateStripGroup(0, 1, CRGB::Red);    // First two strips
    updateStripGroup(2, 3, CRGB::Blue);   // Next two strips
}

Effetti Speculari¶

Rispecchiare una striscia sull’altra:

void mirrorStrips() {
    // Copy strip1 to strip2 in reverse
    for (int i = 0; i < LEDS_PER_STRIP; i++) {
        strip2[i] = strip1[LEDS_PER_STRIP - 1 - i];
    }
}

Passaggi successivi:

  • Sperimentare con gli sfasamenti tra le strisce

  • Provare diversi schemi di coordinamento (circolari, radiali, ecc.)

  • Combinare con la reattività audio per effetti immersivi

  • Creare installazioni con strisce a diverse angolazioni o distanze
