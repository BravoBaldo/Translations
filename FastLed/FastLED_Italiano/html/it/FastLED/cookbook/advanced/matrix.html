Quando si lavora con matrici o griglie LED, è necessario mappare le coordinate 2D su un array 1D. Questa guida illustra le tecniche essenziali per la creazione di pattern su matrici LED.

Funzione di Mappatura XY¶

La funzione più importante per le matrici è il mappatore XY, che converte le coordinate 2D in indici di array.

#define MATRIX_WIDTH  16
#define MATRIX_HEIGHT 16
#define NUM_LEDS (MATRIX_WIDTH * MATRIX_HEIGHT)

CRGB leds[NUM_LEDS];

// Convert X,Y to array index
uint16_t XY(uint8_t x, uint8_t y) {
    // Handle out of bounds
    if (x >= MATRIX_WIDTH || y >= MATRIX_HEIGHT) {
        return 0;
    }

    // Serpentine (zigzag) layout
    if (y & 0x01) {
        // Odd rows run backwards
        uint8_t reverseX = (MATRIX_WIDTH - 1) - x;
        return (y * MATRIX_WIDTH) + reverseX;
    } else {
        // Even rows run forwards
        return (y * MATRIX_WIDTH) + x;
    }
}

Comprensione del Layout a Serpentina¶

La maggior parte delle matrici LED è cablata secondo uno schema a serpentina (zigzag):

  • Riga 0: Da sinistra a destra (0, 1, 2, …)

  • Riga 1: Da destra a sinistra (…, 17, 16, 15)

  • Riga 2: Da sinistra a destra (32, 33, 34, …)

Questo layout riduce al minimo la complessità del cablaggio, ma richiede una gestione speciale nel codice.

Pattern 2D¶

Effetto Plasma¶

Creare pattern organici e fluidi utilizzando il rumore 2D:

void plasma() {
    for (uint8_t x = 0; x < MATRIX_WIDTH; x++) {
        for (uint8_t y = 0; y < MATRIX_HEIGHT; y++) {
            // Create 2D sine wave pattern
            uint8_t brightness = qsub8(
                inoise8(x * 30, y * 30, millis() / 10),
                inoise8(x * 50, y * 50, millis() / 20)
            );

            uint16_t index = XY(x, y);
            leds[index] = CHSV(brightness, 255, 255);
        }
    }
}

Forme in Movimento¶

Animare oggetti nella matrice:

void bouncingBall() {
    static float ballX = MATRIX_WIDTH / 2.0;
    static float ballY = MATRIX_HEIGHT / 2.0;
    static float velocityX = 0.3;
    static float velocityY = 0.2;

    // Clear matrix
    fadeToBlackBy(leds, NUM_LEDS, 50);

    // Update position
    ballX += velocityX;
    ballY += velocityY;

    // Bounce off walls
    if (ballX <= 0 || ballX >= MATRIX_WIDTH - 1) velocityX = -velocityX;
    if (ballY <= 0 || ballY >= MATRIX_HEIGHT - 1) velocityY = -velocityY;

    // Draw ball
    leds[XY((uint8_t)ballX, (uint8_t)ballY)] = CRGB::White;
}

Suggerimenti per la Programmazione di Matrici¶

Tipi di Layout¶

Serpentina (Zigzag):

  • Lo schema di cablaggio più comune

  • Richiede logica condizionale nella funzione XY

  • Risparmia i fili e semplifica il layout fisico

Progressiva (righe tutte nella stessa direzione):

  • Funzione XY più semplice: return (y * MATRIX_WIDTH) + x

  • Richiede più cavi

  • Meno comune nelle matrici commerciali

Considerazioni sulle Prestazioni¶

  1. Precalcolare le costanti: memorizzare le dimensioni della matrice e i valori utilizzati di frequente

  2. Utilizzare tabelle di lookup: Per mappature XY complesse, precalcolare e memorizzare gli indici

  3. Ottimizzare i cicli annidati: Considerare l’elaborazione solo dei pixel modificati per effetti complessi

  4. Limitare la risoluzione: Per matrici molto grandi, considerare l’aggiornamento di pixel alterni

Sistemi di Coordinate¶

Ricordare che le matrici LED possono avere punti di origine diversi:

  • Origine in basso a sinistra (più comune)

  • Origine in alto a sinistra (display)

  • Origine centrale (alcuni effetti)

Regolare la funzione XY di conseguenza.

Pattern Comuni¶

Scacchiera¶

void checkerboard() {
    for (uint8_t x = 0; x < MATRIX_WIDTH; x++) {
        for (uint8_t y = 0; y < MATRIX_HEIGHT; y++) {
            CRGB color = ((x + y) % 2) ? CRGB::White : CRGB::Black;
            leds[XY(x, y)] = color;
        }
    }
}

Mappa Termica¶

void heatMap() {
    for (uint8_t x = 0; x < MATRIX_WIDTH; x++) {
        for (uint8_t y = 0; y < MATRIX_HEIGHT; y++) {
            // Distance from center
            int dx = x - MATRIX_WIDTH / 2;
            int dy = y - MATRIX_HEIGHT / 2;
            uint8_t distance = sqrt(dx * dx + dy * dy) * 10;

            leds[XY(x, y)] = ColorFromPalette(HeatColors_p, distance);
        }
    }
}

Risoluzione dei problemi¶

Posizioni pixel errate:

  • Verificare il modello di cablaggio della matrice (serpentina o progressiva)

  • Verificare se l’origine è in basso a sinistra o in alto a sinistra

  • Testare con un modello semplice come la scacchiera

Problemi di prestazioni:

  • Ridurre la risoluzione della matrice

  • Ottimizzare i loop annidati

  • Usare EVERY_N_MILLISECONDS per limitare la frequenza di aggiornamento

  • Considerare FastLED.setMaxRefreshRate()

Limitazioni di memoria:

  • Ogni LED utilizza 3 byte (RGB)

  • Matrice 16x16 = 768 byte

  • Lasciare spazio per altre variabili e spazio di stack

Passaggi successivi:

  • Provare a combinare modelli 2D con tavolozze di colori

  • Sperimentare con diverse scale di rumore per effetti unici

  • Aggiungere interattività con sensori o controlli
