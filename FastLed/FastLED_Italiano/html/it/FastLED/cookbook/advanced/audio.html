Pattern reattivi all’audio¶

⚠️ SPERIMENTALE: Questa documentazione riguarda le funzionalità audio sperimentali attualmente in fase di sviluppo. Le API di rilevamento dei “beat” FastLED sono state introdotte nell’ottobre 2025 e sono ancora in fase di evoluzione. Gli esempi di codice mostrati qui illustrano i concetti generali di reattività all’audio, ma potrebbero non riflettere l’API finale.

[fuzzy]Creare visualizzazioni LED che rispondono all’input audio. Questa guida illustra la lettura dei segnali audio e la creazione di effetti reattivi.

Configurazione Audio di Base¶

Per leggere l’audio, è necessario un ingresso analogico collegato a un microfono o a una linea audio.

Requisiti Hardware¶

  • Microcontrollore con ingresso analogico (la maggior parte delle schede compatibili con Arduino)

  • Modulo microfono electret o circuito di ingresso audio

  • Opzionale: amplificatore per microfono MAX4466 o simile per una migliore sensibilità

Lettura dei Livelli Audio¶

#define MIC_PIN A0
#define SAMPLE_WINDOW 50  // Sample window width in ms

uint16_t readAudioLevel() {
    unsigned long startMillis = millis();
    uint16_t peakToPeak = 0;
    uint16_t signalMax = 0;
    uint16_t signalMin = 1024;

    // Collect data for sample window
    while (millis() - startMillis < SAMPLE_WINDOW) {
        uint16_t sample = analogRead(MIC_PIN);
        if (sample > signalMax) signalMax = sample;
        if (sample < signalMin) signalMin = sample;
    }

    peakToPeak = signalMax - signalMin;
    return peakToPeak;
}

Questa funzione misura l’ampiezza picco-picco del segnale audio in un breve intervallo di tempo, fornendo una lettura del livello del volume corrente.

Effetto VU Meter¶

Una visualizzazione classica che mostra il livello audio come una barra crescente/diminuente.

void vuMeter() {
    uint16_t audioLevel = readAudioLevel();

    // Map to LED count (0 to NUM_LEDS)
    uint8_t numLEDsToLight = map(audioLevel, 0, 1023, 0, NUM_LEDS);

    // Clear all
    fill_solid(leds, NUM_LEDS, CRGB::Black);

    // Light up LEDs based on level
    for (int i = 0; i < numLEDsToLight; i++) {
        // Color gradient: green -> yellow -> red
        uint8_t hue = map(i, 0, NUM_LEDS, 96, 0);  // Green to red
        leds[i] = CHSV(hue, 255, 255);
    }
}

Variazioni del VU Meter¶

Con Peak Hold:

void vuMeterWithPeak() {
    static uint8_t peak = 0;
    static unsigned long lastPeakTime = 0;

    uint16_t audioLevel = readAudioLevel();
    uint8_t numLEDsToLight = map(audioLevel, 0, 1023, 0, NUM_LEDS);

    // Update peak
    if (numLEDsToLight > peak) {
        peak = numLEDsToLight;
        lastPeakTime = millis();
    }

    // Peak decay
    if (millis() - lastPeakTime > 1000) {
        if (peak > 0) peak--;
        lastPeakTime = millis();
    }

    // Draw VU meter
    fill_solid(leds, NUM_LEDS, CRGB::Black);
    for (int i = 0; i < numLEDsToLight; i++) {
        uint8_t hue = map(i, 0, NUM_LEDS, 96, 0);
        leds[i] = CHSV(hue, 255, 255);
    }

    // Draw peak indicator
    if (peak < NUM_LEDS) {
        leds[peak] = CRGB::White;
    }
}

Rilevamento del Battito¶

Rileva i ritmi nella musica per effetti reattivi.

class BeatDetector {
private:
    uint16_t samples[32];
    uint8_t sampleIndex = 0;
    uint32_t lastBeatTime = 0;

public:
    bool detectBeat(uint16_t audioLevel) {
        // Store sample
        samples[sampleIndex] = audioLevel;
        sampleIndex = (sampleIndex + 1) % 32;

        // Calculate average
        uint32_t sum = 0;
        for (int i = 0; i < 32; i++) sum += samples[i];
        uint16_t average = sum / 32;

        // Detect beat (current level significantly above average)
        bool isBeat = (audioLevel > average * 1.5) &&
                      (millis() - lastBeatTime > 300);  // Minimum 300ms between beats

        if (isBeat) lastBeatTime = millis();
        return isBeat;
    }
};

BeatDetector beatDetector;

void beatEffect() {
    uint16_t audioLevel = readAudioLevel();

    if (beatDetector.detectBeat(audioLevel)) {
        // Flash on beat
        fill_solid(leds, NUM_LEDS, CRGB::White);
    } else {
        // Fade out
        fadeToBlackBy(leds, NUM_LEDS, 10);
    }
}

Effetti sincronizzati al ritmo¶

Cambio di colore a battuta:

void beatColorChange() {
    static uint8_t currentHue = 0;
    uint16_t audioLevel = readAudioLevel();

    if (beatDetector.detectBeat(audioLevel)) {
        currentHue += 32;  // Change color on beat
    }

    // Fade to current color
    CRGB targetColor = CHSV(currentHue, 255, 255);
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = blend(leds[i], targetColor, 50);
    }
}

Impulso a battuta:

void beatPulse() {
    static uint8_t pulseIntensity = 0;
    uint16_t audioLevel = readAudioLevel();

    if (beatDetector.detectBeat(audioLevel)) {
        pulseIntensity = 255;
    }

    // Draw pulsing effect
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = CHSV(160, 255, pulseIntensity);
    }

    // Fade out
    if (pulseIntensity > 0) pulseIntensity -= 5;
}

Effetti Audio Avanzati¶

Bande di Frequenza (richiede FFT)¶

Per una reattività audio più sofisticata, utilizzare la FFT (Trasformata di Fourier rapida) per analizzare le bande di frequenza. Richiede librerie aggiuntive come:

  • arduinoFFT

  • fix_fft

Esempio di concetto (richiede la libreria FFT):

// Pseudo-code - requires FFT library
void frequencyBands() {
    // Perform FFT on audio samples
    // Extract bass, mid, treble

    uint8_t bass = getBassLevel();    // 0-255
    uint8_t mid = getMidLevel();      // 0-255
    uint8_t treble = getTrebleLevel(); // 0-255

    // Map to different parts of strip
    int bassLEDs = NUM_LEDS / 3;
    int midLEDs = NUM_LEDS / 3;
    int trebleLEDs = NUM_LEDS / 3;

    // Bass: red
    fill_solid(&leds[0], bassLEDs, CRGB::Red);
    fadeToBlackBy(&leds[0], bassLEDs, 255 - bass);

    // Mid: green
    fill_solid(&leds[bassLEDs], midLEDs, CRGB::Green);
    fadeToBlackBy(&leds[bassLEDs], midLEDs, 255 - mid);

    // Treble: blue
    fill_solid(&leds[bassLEDs + midLEDs], trebleLEDs, CRGB::Blue);
    fadeToBlackBy(&leds[bassLEDs + midLEDs], trebleLEDs, 255 - treble);
}

Suggerimenti per effetti reattivi all’audio¶

Calibrazione¶

Regola la sensibilità in base alla sorgente audio:

// For quiet environments
uint16_t calibratedLevel = map(audioLevel, 0, 200, 0, 1023);

// For loud environments
uint16_t calibratedLevel = map(audioLevel, 100, 800, 0, 1023);

Smoothing¶

Letture audio fluide per evitare jitter:

uint16_t smoothAudio(uint16_t newValue) {
    static uint16_t lastValue = 0;
    lastValue = (lastValue * 7 + newValue) / 8;  // Exponential smoothing
    return lastValue;
}

Prestazioni¶

L’elaborazione audio può richiedere molta CPU:

  • Utilizzare finestre di campionamento più brevi per una risposta più rapida

  • Limitare la risoluzione FFT se si utilizza l’analisi di frequenza

  • Valutare l’utilizzo di interrupt per il campionamento audio

  • Testare il frame rate per garantire aggiornamenti LED fluidi

Risoluzione dei problemi¶

Nessuna risposta audio:

  • Controllare il cablaggio e l’alimentazione del microfono

  • Verificare che il pin analogico nel codice corrisponda all’hardware

  • Eseguire un test con Serial.println(audioLevel) per visualizzare le letture grezze

  • Regolare le soglie di calibrazione

Troppo sensibile/non abbastanza sensibile:

  • Regolare gli intervalli di map() nella calibrazione

  • Controllare il guadagno del microfono se si utilizza un microfono amplificato

  • Modificare la soglia di rilevamento dei battiti (attualmente 1,5x la media)

Movimento a scatti:

  • Aggiungere smoothing alle letture audio

  • Aumentare la dimensione della finestra di campionamento

  • Utilizzare lo smoothing esponenziale o la media mobile

Rilevamento dei falsi battiti:

  • Aumentare il tempo minimo tra i battiti (attualmente 300 ms)

  • Regolare il moltiplicatore di soglia (attualmente 1,5)

  • Aumentare la dimensione del buffer di campionamento per un calcolo migliore della media

Passaggi successivi:

  • Sperimentare diversi valori di soglia per il proprio ambiente

  • Combinare la reattività audio con altri effetti (rumore, palette)

  • Provare più strisce LED che reagiscono a diversi bande di frequenza
