Problemi di Caduta di Tensione¶

Problema: Gli ultimi LED sono deboli o di colore sbagliato

Causa: Caduta di tensione su strisce lunghe dovuta alla resistenza del filo

Soluzioni:

  • Utilizzare fili di alimentazione più spessi (18-22 AWG [0.6-1mm] per tratti corti)

    • Filo più spesso = minore resistenza = minore caduta di tensione

    • 18 AWG [1mm] per correnti elevate o corse più lunghe

    • 22-24 AWG [0.5-0.6mm] accettabile per brevi distanze (<90 cm) con pochi LED

  • Alimentare ogni 60-100 LED su strisce lunghe

    • Non fare affidamento sulla corrente che attraversa l’intera striscia

    • Collegare 5 V e GND direttamente in più punti

    • Fondamentale per strisce con oltre 100 LED

  • Collegare 5 V e GND a entrambe le estremità della striscia

    • Riduce la resistenza effettiva della metà

    • Soluzione semplice per strisce di media lunghezza

  • Utilizzare un alimentatore separato (non alimentare dal microcontrollore)

    • I pin del microcontrollore non forniscono corrente sufficiente

    • Pin 5 V Arduino: max ~200 mA (solo 3-4 LED alla massima luminosità)

    • Utilizzare sempre un alimentatore esterno per le strisce LED

Schema Elettrico Consigliato¶

Power Supply (+5V) ----+---> LED Strip VCC
                       |
                       +---> Microcontroller VIN/5V (if needed)

Power Supply (GND) ----+---> LED Strip GND
                       |
                       +---> Microcontroller GND (MUST share ground!)

Microcontroller GPIO --[220Ω resistor]---> LED Strip DATA

Power Supply (+) --[1000µF capacitor]-- Power Supply (-)

Punti critici:

  • Il microcontrollore e la striscia LED DEVONO condividere la massa comune

  • Alimentare direttamente la striscia LED, non tramite il microcontrollore

  • Condensatore vicino all’alimentatore

  • Resistenza vicino al microcontrollore

Problema: Primo LED di Colore Sbagliato¶

Causa: Problema di integrità del segnale - livelli di tensione o temporizzazione

Soluzioni:

  1. Aggiungere una resistenza da 220-470Ω sulla linea dati (vicino al microcontrollore)

    • Soluzione più efficace

    • Protegge sia il microcontrollore che il LED

    • Posizionare la resistenza entro 15 cm dal microcontrollore

  2. Mantenere il cavo dati corto (< 15 cm se possibile)

    • I cavi più lunghi fungono da antenne per le interferenze

    • Se è necessario un cavo più lungo, utilizzare un cavo schermato

  3. Utilizzare un variatore di livello per la conversione da 3,3 V a 5 V

    • Necessario per ESP8266, alcune schede ESP32

    • Molti WS2812B richiedono un livello logico alto di 3,5 V+

    • 74HCT245 o moduli di traslazione di livello dedicati

    • Alternativa: utilizzare il primo LED come traslazione di livello (alimentarlo a 3,3 V)

  4. Provare a ridurre l’impedenza del pin dati

    • Alcuni pin hanno una migliore potenza di pilotaggio

    • Controllare il datasheet del microcontrollore

Problema: Sfarfallìo Casuale¶

Cause e Soluzioni:

1. Insufficient Power Supply Capacity¶

Problem: Supply can't provide enough current
Solution:
- Use power supply rated 20% higher than calculated need
- Example: 100 LEDs × 60mA = 6A needed, use 8A supply
- Cheap supplies often don't meet rated specs

2. Poor Ground Connection¶

Problem: Unstable ground reference
Solution:
- Ensure microcontroller GND connects to LED strip GND
- Use star grounding (all GNDs meet at one point)
- Use thick wire for ground (same gauge as 5V wire)

3. Electrical Interference¶

Solutions:
- Keep data wire away from power wires (at least 1 inch separation)
- Add 0.1µF ceramic capacitor near each LED strip section
- Use shielded cable for data line in noisy environments
- Avoid running LED wires parallel to AC power lines

4. Software Timing Issues¶

Solutions:
// Disable interrupts during FastLED.show()
// (FastLED does this automatically on most platforms)

// Avoid WiFi/Bluetooth during LED updates on ESP32
#ifdef ESP32
  esp_wifi_stop();  // Before FastLED.show()
  FastLED.show();
  esp_wifi_start(); // After
#endif

Problema: i LED Non Si Accendono¶

Checklist completa:

Hardware:
[ ] Power supply voltage correct (5V for most strips)
[ ] Power supply capacity sufficient (60mA per LED at full white)
[ ] Power supply plugged in and turned on
[ ] Positive and negative not reversed
[ ] Data pin correct in code (matches wiring)
[ ] LED type correct (WS2812B, APA102, etc.)
[ ] COLOR_ORDER correct (try GRB if RGB doesn't work)
[ ] Strip not damaged (test with known-good controller)
[ ] Wires making solid contact (no loose connections)
[ ] Ground shared between microcontroller and LED strip

Software:
[ ] FastLED.show() being called
[ ] Brightness not set to 0
[ ] LED array actually being set to colors (not all black)
[ ] Correct pin definitions for your board

Test sistematici:

  1. Misurare la tensione di alimentazione con un multimetro (dovrebbe essere 4,5-5,5 V)

  2. Verificare il funzionamento del microcontrollore (LED integrato lampeggiante)

  3. Provare lo sketch di test minimo (vedere Suggerimenti per il Debug)

  4. Provare con un solo LED

  5. Controllare con un oscilloscopio, se disponibile (la linea dati dovrebbe mostrare il segnale)

Problema: La Striscia Funziona Parzialmente¶

Scenario: I primi N LED funzionano, gli altri no

Cause:

  1. Guasto a un LED nella striscia

  2. Degrado del segnale dati

  3. Alimentazione insufficiente

Soluzioni:

1. Find the Bad LED¶

Process:
1. Identify last working LED
2. Suspect the LED immediately after (or the last working one)
3. Test by:
   - Setting NUM_LEDS to last working position
   - See if strip works reliably
4. Cut out failed LED and reconnect data line
5. Consider that last working LED might be damaged (weak output)

2. Signal Boost¶

Hardware solutions:
- Add 220Ω resistor on data line (if not already present)
- Use level shifter for 3.3V systems
- Reduce strip length or split into sections
- Inject data signal midway through strip with buffer IC

3. Power Injection¶

Even if data signal is good, insufficient power causes issues:
- Add power injection every 50-100 LEDs
- Connect 5V and GND directly to strip at injection points
- Don't connect multiple power supplies in parallel (unless same model)

Problemi specifici dell’ESP32¶

Problema: I LED Si Spengono Durante l’Attività WiFi¶

Causa: Gli interrupt del WiFi interferiscono con la temporizzazione dei LED

Soluzione 1 - Disattivare il WiFi Durante gli Aggiornamenti:

void loop() {
    // Pause WiFi
    #ifdef ESP32
    esp_wifi_stop();
    #endif

    updateLEDs();
    FastLED.show();

    #ifdef ESP32
    esp_wifi_start();
    #endif

    // Do WiFi tasks
    delay(10);
}

Soluzione 2 - Utilizzare una Periferica RMT (Meglio):

// FastLED automatically uses RMT on ESP32 if pin supports it
// RMT is immune to WiFi interference
// Use pins: 2, 4, 5, 12-19, 21-23, 25-27, 32-33
#define LED_PIN 16  // RMT-capable pin

Soluzione 3 - Attivare i LED sul Secondo Core:

// Use separate task on second CPU core
void ledTask(void* parameter) {
    while (true) {
        updateLEDs();
        FastLED.show();
        delay(20);
    }
}

void setup() {
    // Start LED task on core 0 (Arduino uses core 1)
    xTaskCreatePinnedToCore(
        ledTask,   // Function
        "LEDs",    // Name
        10000,     // Stack size
        NULL,      // Parameters
        1,         // Priority
        NULL,      // Task handle
        0          // Core (0 or 1)
    );
}

Selezione dei pin dell’ESP32¶

Good pins for LEDs (RMT support):
- GPIO 2, 4, 5
- GPIO 12-19
- GPIO 21-23
- GPIO 25-27
- GPIO 32-33

Avoid:
- GPIO 0, 2 (boot pins - can cause issues)
- GPIO 6-11 (connected to flash)
- GPIO 34-39 (input only)

Guida alla Selezione dell’Alimentatore¶

Calcolare la potenza richiesta e selezionare l’alimentatore appropriato:

LED Count | Max Current (Full White) | Recommended Supply | Typical Cost
----------|---------------------------|-------------------|-------------
30        | 1.8A                     | 2.5A              | $10-15
60        | 3.6A                     | 5A                | $15-20
100       | 6.0A                     | 8A                | $20-30
150       | 9.0A                     | 12A               | $30-40
200       | 12.0A                    | 15A               | $40-60

Note: Full white is worst case. Most patterns use 30-50% of max.

Importante: Utilizzare setMaxPowerInVoltsAndMilliamps() per limitare l’assorbimento di corrente:

void setup() {
    // Limit to 2A at 5V
    FastLED.setMaxPowerInVoltsAndMilliamps(5, 2000);
}

Requisiti dell’alimentatore:

  • Tensione: 5 V CC (la maggior parte dei LED), regolata

  • Corrente: Calcolare in base al numero di LED + margine del 20%

  • Qualità: Utilizzare un alimentatore con uscita stabile, buone recensioni

  • Evitare: Alimentatori economici senza marchio, amperaggio insufficiente, alimentatori da 12 V

Test dell’Hardware¶

Codice di test completo per la validazione dell’hardware:

// Comprehensive hardware test
void hardwareTest() {
    Serial.begin(115200);
    delay(1000);

    Serial.println("=== FastLED Hardware Test ===");

    // Test 1: Single LED
    Serial.println("Test 1: First LED RED");
    FastLED.clear();
    leds[0] = CRGB::Red;
    FastLED.show();
    delay(2000);

    // Test 2: All RED
    Serial.println("Test 2: All LEDs RED");
    fill_solid(leds, NUM_LEDS, CRGB::Red);
    FastLED.show();
    delay(2000);

    // Test 3: Color test
    Serial.println("Test 3: Color sequence");
    CRGB colors[] = {CRGB::Red, CRGB::Green, CRGB::Blue, CRGB::White};
    for (int c = 0; c < 4; c++) {
        fill_solid(leds, NUM_LEDS, colors[c]);
        FastLED.show();
        delay(1000);
    }

    // Test 4: Individual LEDs
    Serial.println("Test 4: Individual LED scan");
    FastLED.clear();
    for (int i = 0; i < NUM_LEDS; i++) {
        leds[i] = CRGB::White;
        FastLED.show();
        delay(50);
        leds[i] = CRGB::Black;
    }

    Serial.println("=== Test Complete ===");
}

Modalità d’uso:

  1. Caricare questo come sketch (chiamato da setup())

  2. Aprire Serial Monitor (115200 baud)

  3. Osservare quale test non riesce a identificare il problema

  4. Se il Test 1 fallisce: problema di connessione dati o alimentazione

  5. Se il Test 2 fallisce: alimentazione insufficiente

  6. Se il Test 3 mostra colori errati: COLOR_ORDER errato

  7. Se il Test 4 fallisce su un LED specifico: LED difettoso o degradazione del segnale

Esempio di Iniezione di Potenza¶

Per strisce più lunghe di 100 LED:

Power Supply (+5V) ---+---> Strip Start VCC
                      |
                      +---> Strip Middle VCC (at LED 100)
                      |
                      +---> Strip End VCC (at LED 200)

Power Supply (GND) ---+---> Strip Start GND
                      |
                      +---> Strip Middle GND
                      |
                      +---> Strip End GND

Microcontroller ------[resistor]---> Strip Start DATA

Considerazioni sul codice:

// No code changes needed for power injection
// It's purely a wiring modification
// LEDs will be brighter and more consistent

Guida al Test con Multimetro¶

Utilizzare un multimetro per verificare l’hardware:

Test 1: Tensione di alimentazione

1. Set multimeter to DC voltage (20V range)
2. Measure power supply output (no load)
3. Should read 4.5-5.5V (ideally 5.0-5.2V)
4. Measure again with LEDs connected (under load)
5. Should not drop below 4.5V

Test 2: Tensione sulla striscia

1. Measure voltage at strip start (at VCC and GND pads)
2. Should be same as power supply (minimal drop)
3. Measure at strip end
4. With LEDs on, should not drop more than 0.5V
5. Large drop indicates insufficient wire gauge

Test 3: Continuità

1. Set multimeter to continuity mode
2. Test ground connection: microcontroller GND to strip GND
3. Should beep (indicating connection)
4. Test data connection: microcontroller pin to strip DATA
5. Should beep

Errori Comuni di Cablaggio¶

Evitare questi errori frequenti:

  1. Non condividere la massa

    • La massa del microcontrollore deve essere collegata alla massa della striscia LED

    • Errore più comune per i principianti

  2. Alimentare i LED dal microcontrollore

    • Il pin 5V di Arduino non fornisce corrente sufficiente

    • Utilizzare un alimentatore esterno

  3. Polarità invertita

    • Verificare che +5V e GND non siano invertiti

    • Può danneggiare i LED all’istante

  4. Nessun condensatore sull’alimentatore

    • Causa sfarfallio e instabilità

    • Utilizzare sempre 1000 µF o più grandi

  5. Cavo sottile per l’alimentazione

    • Utilizzare un calibro appropriato (18-22 AWG [0.6-1mm])

    • La caduta di tensione causa la fioca luminosità dei LED

  6. Cavo dati Lungo senza resistenza

    • Problemi di integrità del segnale

    • Primi problemi al LED

  7. Cavo dati troppo vicino al cavo di alimentazione

    • Interferenza elettromagnetica

    • Provoca sfarfallio casuale
